# 当前实验数据集：ADNI与MIMIC的队列、信息范围和预处理

## 1. 从原始病例到当前实验队列

当前纵向预测实验把患者的多次记录整理为一条时间序列：每个时间点包含检查数值、类别资料和观测掩码。模型读取一段历史，再重构历史并预测未来记录。

本文件对应 latent2x both 及同任务 baseline 实际使用的两份缓存：

- **ADNI：** `paper_odeae/cache/local_available.pkl`，40字段协议。
- **MIMIC-IV 3.1：** `/data/MIMIC/derived/latentode_iv31/dataset.pkl`，`chronology_v2`版本。

下面先分别说明队列从哪里来、哪些信息进入缓存、怎样处理时间和缺失，再说明如何形成训练与测试任务。人数、记录数和模态覆盖均从这两份实际缓存重新统计，并核对了已有训练记录中的数据SHA256。

## 3. ADNI队列与预处理

### 3.1 数据来源和患者名单

原始数据根目录为：

```text
/data/SAMSUNG_backup/ADNI_data/
```

当前预处理从 `Enrollment/`、`Neuropsychological/`、`Biospecimen/`、`MRI_PET_csv/` 中的结构化CSV读取数值。患者名单和分组来自：

```text
ADNI_multimodal_timeline/indexes/patients.csv
ADNI_multimodal_timeline/indexes/patient_splits.csv
```

程序通过 `PTID` 匹配患者；使用 `RID` 的表先借助患者索引转为同一患者编号。

### 3.2 哪些患者进入纵向实验

先读取已有分组，再整理患者检查日期和季度记录。每个有效季度需要有可用日期和35至120岁范围内的年龄；患者最终至少保留两个严格递增的季度时间点。

| 已有患者分组 | 原清单患者 | 未满足有效纵向条件 | 最终患者 | 最终季度记录 |
|---|---:|---:|---:|---:|
| 训练 | 2,199 | 106 | **2,093** | 12,544 |
| 验证 | 420 | 27 | **393** | 2,219 |
| 测试 | 446 | 32 | **414** | 2,402 |
| 合计 | 3,065 | 165 | **2,900** | **17,165** |

这里的有效纵向条件同时涉及日期、年龄和季度数量。最终患者的首末记录间隔中位数约为3年，最长约20.75年。

患者可以在某个季度只提供部分检查项目。各项目以自己的掩码进入联合序列，因此队列能保留模态覆盖不同的患者。

| MRI海马体积变化 | 2,834 | 2,227 | 11,118 |

人口学静态资料与APOE会复制到患者各个有效季度，所以这些字段的多季度出现表示重复提供同一静态信息。MRI、PET、认知和CSF行统计的是对应季度的有效检查字段。

### 3.5 先合并访视，再聚合季度

**第一步：确定一条记录属于哪次访视。** 使用“患者编号＋PHASE＋VISCODE2”，VISCODE2缺失时使用VISCODE。PHASE缺失的记录在键中加入日期，保留不同日期的记录。

**第二步：确定访视日期。** 优先使用EXAMDATE；有多个EXAMDATE时取最早。之后依次使用VISDATE、SCANDATE。同一访视中，同一数值字段先取均值，类别字段取众数。

**第三步：按自然年季度合并。** 1至3月、4至6月、7至9月、10至12月分别形成一个季度。季度内数值再次取均值、类别取众数。时间戳放在3月31日、6月30日、9月30日或12月31日。

例如，同一季度内不同日期完成的量表和PET定量结果，会在该季度末形成一条包含多个字段的记录。空季度保留为时间间隔，序列中存放有有效记录的季度。

### 3.6 MRI、PET和静态资料如何变为字段

| 信息 | 实际转换规则 |
|---|---|
| MRI | 读取FreeSurfer表的左右海马体积，排除明确的整体或海马QC失败记录，再将双侧体积求和 |
| 海马变化率 | 对每位患者取首次有效季度的海马体积为基准，计算 `100×(当前体积/首次体积−1)` |
| 淀粉样PET、tau PET | 保留`qc_flag=2`，读取合格皮层区域SUVR及其体积，按体积加权汇总为皮层SUVR |
| 脑脊液 | 从本地`UPENNBIOMK_ROCHE_ELECSYS`源表读取Aβ42、Aβ40、pTau对应列 |
| 人口学 | 从PTDEMOG按VISDATE排序的最早记录取得性别、婚姻、教育、利手资料 |
| APOE | 从基因型读取两条等位基因，统计ε4数量，作为静态字段 |
| 诊断 | 将源表诊断或相应诊断标记映射为CN=0、MCI=1、Dementia=2 |

年龄根据出生日期和季度末计算，以365.25天为一年。有出生年月时使用该月1日；只有出生年份时使用当年7月1日。年龄同时形成数值字段和数据时间轴。

### 3.7 数值清理与类别编码

非数值内容、NaN、Inf以及负的无效编码按缺失处理。海马体积变化等变化率允许负值。类别字段检查是否为有效整数编码；性别、婚姻、利手的源编码转成从0开始的类别。

四个类别字段分别为2、5、3、3类，因此展开后的任务维度为：

\[
36+2+5+3+3=49.
\]

### 3.8 患者怎样划分

当前实验直接读取 `patient_splits.csv` 的患者成员映射。完成纵向筛选后，继续保留每位患者原有的训练、验证或测试身份，最终人数为2,093、393、414。

同一患者的全部季度、全部历史前缀使用同一分组。患者分组固定在缓存中；网络训练的随机种子用于参数和批次等随机过程。

### 4.1 数据版本与原始表

本地原始归档为 `/data/MIMIC/mimic-iv-3.1.zip`，本轮使用MIMIC-IV 3.1。版本出处见[PhysioNet发布页](https://www.physionet.org/content/mimiciv/3.1/)。

| 原始表 | 在当前流程中的作用 |
|---|---|
| `hosp.patients` | 患者编号、性别、年龄锚点 |
| `hosp.admissions` | 住院编号、起止时间、死亡时间与人群描述信息 |
| `icu.icustays` | ICU住院编号、入科和出科时间 |

| `icu.d_items`、`hosp.d_labitems` | 核对项目编码、名称及来源 |

MIMIC的模型输入由结构化临床观测和人口学信息构成。当前缓存按上述项目提取，医院死亡标记保留为队列元数据。

### 4.2 从ICU住院记录筛到纵向队列

每位患者先取时间最早的ICU住院，再应用年龄和观察窗口条件。

| 筛选步骤 | 剩余数量 |
|---|---:|
| 原始ICU住院记录 | 94,458次 |
| 每位患者取首次ICU住院，年龄估计值至少18岁 | 65,366人 |
| 首次ICU住院时长至少48小时 | 31,142人 |
| 前24小时、后24小时各至少6个非空观测窗口 | 31,072人 |
| 前48小时满足住院及死亡时间核查 | **30,702人** |

时间核查要求：

1. ICU入科时间不早于本次住院开始。
2. ICU入科后48小时的端点不晚于本次出院。
3. 死亡时间为空，或不早于该48小时端点。

观测支持筛选移除70人，后续时间核查再移除370人。最终版本记为 `chronology_v2`。由此得到的队列是首次ICU住院且具有前48小时观察支持的成年患者。

### 4.4 各类信息覆盖多少患者

下表以最终30,702人为分母。一个小时内某组至少有一项有效字段，就计为该组出现一次。

| 信息类别 | 至少一条记录的患者 | 至少两个小时有记录的患者 | 有该组信息的小时窗口 |
|---|---:|---:|---:|
| 生命体征与体重 | 30,688 | 30,686 | 1,094,772 |

| GCS意识状态 | 30,686 | 30,683 | 395,644 |
| 性别 | 30,702 | 0 | 30,702 |

性别这一行反映“只提供一次静态信息”的设计。其他三类信息保留各自的观测频率。

### 4.5 先确定记录在何时可以获得

对每条临床记录，使用测量时间 `charttime` 和入库时间 `storetime` 中较晚者作为可用时间：

\[
t_{\mathrm{available}}=\max(t_{\mathrm{chart}},t_{\mathrm{store}}).
\]

缺少入库时间时使用测量时间。官方[labevents字段说明](https://mimic.mit.edu/docs/iv/modules/hosp/labevents.html)将storetime定义为结果在实验室系统中可供使用的时间。

例如，第5.2小时采样、第7.4小时入库的结果，进入第7至8小时的窗口，并在第8小时窗口结束时提供给模型。目标记录也采用相同时间规则。

关联记录时，chartevents按 `stay_id` 匹配ICU住院；化验按患者和时间窗口匹配，有 `hadm_id` 时还要求住院编号一致。缺少 `hadm_id` 的化验使用同一患者与选定窗口关联。

### 4.6 单位、质量范围与小时聚合

只保留入ICU后 `[0,48)` 小时内可获得的记录，并进行以下处理：

| 处理 | 当前规则 |
|---|---|
| 项目映射 | 多个对应同一指标的itemid合并到同一字段 |
| 体温 | 华氏度转摄氏度 |
| FiO₂ | 百分数转成0–1比例 |
| 数值质量筛选 | 使用schema中明确记录的下界与上界，保留有限数值 |
| GCS编码 | 保留各项合法整数类别，转成从0开始的编码 |
| 性别编码 | F=0、M=1 |
| 同一小时的数值 | 取均值 |
| 同一小时的GCS | 取众数，并列时取较小编码 |
| 完全没有动态观测的小时 | 在序列中移除，时间轴保留间隔 |

第0至1小时的窗口记为时间1，第47至48小时的窗口记为时间48。因此，序列时间戳位于1至48之间。

例如，一位患者第4小时之后的下一条记录在第6小时，模型收到的时间差为2小时。缓存保留这种不规则间隔。

### 4.7 年龄与小时数分别提供

入ICU年龄估计为：

\[
a_{\mathrm{ICU}}=\mathrm{anchor\_age}+\mathrm{year(intime)}-\mathrm{anchor\_year}.
\]

它使用去标识化年龄锚点。MIMIC对锚点年份超过89岁的患者将anchor_age设为91，规则见[patients官方说明](https://mimic.mit.edu/docs/iv/modules/hosp/patients.html)。

在历史截止时刻，再加上已过小时数除以8766，得到以年表示的年龄。模型的年龄初始化或年龄编码使用这一信息；数据时间轴继续使用ICU小时数。

### 4.8 患者怎样划分

按患者编号构造固定哈希：

```python
text = f"mimiciv31/seed0/{int(subject_id)}"
u = int(hashlib.sha256(text.encode()).hexdigest()[:16], 16) / 2**64
```

| 哈希区间 | 划分 | 最终患者 | 最终小时记录 |
|---|---|---:|---:|
| `u < 0.70` | 训练 | **21,517** | 828,033 |
| `0.70 ≤ u < 0.85` | 验证 | **4,649** | 179,406 |
| `u ≥ 0.85` | 测试 | **4,536** | 174,203 |
| 合计 | | **30,702** | **1,181,642** |

分组由患者编号决定，固定保存在缓存中。同一患者只对应选定的一次ICU住院，其全部记录使用同一分组。

## 5. 两个数据集共享的输入表示

### 5.1 数值、掩码和时间

每位患者保存以下主要内容：

| 内容 | ADNI | MIMIC |
|---|---|---|
| `values[T,F]` | 40字段的归一化数值或类别索引 | 31字段的归一化数值或类别索引 |
| `mask[T,F]` | 每季度每字段是否有有效观测 | 每小时每字段是否有有效观测 |
| `ages[T]` | 以年表示的患者年龄时刻 | 入ICU后的小时数 |
| `subject_id` | 患者编号 | 患者编号 |
| `split` | 固定患者分组 | 固定患者分组 |
| 其他 | 季度末日期 | 住院/ICU编号、年龄估计、统计元数据 |

缺失位置使用0占位，对应掩码为0；评分只汇总掩码为1的标签。缓存保留真实观测间隔，各字段按实际可用情况参加输入和损失。

### 5.2 使用训练患者拟合数值变换

每个数值字段只使用训练患者的有效观测计算min和max：

\[
\widetilde y_j=\frac{y_j-\min_{\mathrm{train},j}}
{\max_{\mathrm{train},j}-\min_{\mathrm{train},j}}.
\]

分母至少取 `1e-6`。验证与测试使用同一组参数，超出训练范围的值照常保留。类别字段保持整数类别索引，在模型输入适配时展开。

HealthFlux在数值输入端再使用训练均值和标准差转换为z-score，并截断到[-10,10]；监督目标仍采用共同的min-max尺度。

ADNI的海马变化率先按患者自身首次有效体积定义，再参与上述训练集数值变换。

### 5.3 数据时间与模型适配

本文件的时间单位和随访统计均以缓存中的物理时间为准。当前latent2x both在ADNI按年、在MIMIC按小时推进。既有ADNI的部分baseline适配器在模型内部将年换算为十年；患者分组和目标时刻继续由同一缓存提供。

MIMIC的年龄在31字段之外通过 `initialization_age` 提供给数据批次。年龄初始化模型、条件年龄编码模型，以及使用年龄协变量的GRU模型，都从这份已知年龄信息取值，任务目标维度保持44。

## 6. 从患者序列形成训练与测试任务

### 6.1 ADNI：枚举历史前缀

一位患者有N个季度，就形成N个历史前缀。第c个任务读取前c个季度，以后各季度作为未来目标，已知季度参与历史重构。

因此，当前ADNI训练、验证和测试的前缀样本数分别为 **12,544、2,219、2,402**。它们恰好等于各集合的季度记录数，因为每个时间点都作为一次历史截止点。

例如，有四个季度的患者形成“读1次”“读前2次”“读前3次”“读全部4次”四个任务。每个任务都使用该患者完整目标序列，按历史与未来区域分别评分。

### 6.2 MIMIC：固定主要评测窗口

| 阶段 | 历史构造 | 预测范围 |
|---|---|---|
| 训练 | 每人每轮从合格的6、12、18、24小时截止点中选一个 | 截止点之后至第48小时 |
| 主要验证、测试 | 前24小时 | 第24小时之后至第48小时 |
| 补充测试 | 前6小时或前12小时 | 各自截止之后至第48小时 |

训练候选截止点要求历史和未来各至少有两条记录。选择由训练seed、轮次和患者编号共同确定。每轮训练使用21,517位患者各一个任务。

主要测试包含全部4,536位测试患者。6小时历史的补充测试有4,513位，12小时历史有4,536位符合对应观测条件。

### 6.3 历史输入与监督标签分别组织

数据批次用独立的历史输入掩码限定可读取范围。训练时对可输入字段使用0.1的观测dropout；原始有效标签掩码保留，用于计算误差。验证和测试使用完整的已知历史。

同一患者的不同历史任务始终属于同一数据划分。各模型使用相同患者、字段、截止点规则和目标掩码。
