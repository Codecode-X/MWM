|---|---|---|

自回归的 `prediction[:, :, i]` 在读入 `x_i` **之前**产生，对应 `p(x_i | x_<i, t_<=i)`。因此不能把读入 `x_i` 后的重构当成一步预测指标。隐藏状态随后才更新；分类使用完成历史条件化的状态。

Latent ODE 解码显式包含后验的时间锚点；查询的第一个时间晚于锚点时，仍先从锚点积分，避免把初始状态错误地放到查询首时刻。插值以最早并集时间为共同先验锚点，外推以共同历史末端为锚点。

生成 ODE 与识别 ODE 参数独立；生成过程中不读入观测。通过重参数采样给出随机轨迹，评估取三个解码轨迹的平均预测计算 MSE，并固定随机种子。无 Transformer、时间位置编码、evidential loss、额外分类校准或类别重采样。

## 本地数据与论文实验的区别

当前 CSV 是 100 名患者、3518 条记录、6 个连续特征的**合成 ICU 数据**，不是论文的 PhysioNet、MuJoCo、Human Activity 或正弦 toy 数据。原始数据生成脚本 `setup.py` 的最大采集窗口为 72 小时；实际最大时间 70.97 小时。未重新生成数据，也未使用旧 processed pickle。

本地实验使用患者级、标签分层的 70/15/15 训练/验证/测试划分，seed=42。论文采用 80/20 训练/测试；这里单独设置验证集以选择检查点。所有模式使用相同患者划分，仅训练集拟合逐特征 min-max 参数；验证与测试超出训练范围的值不会被裁剪。时间统一除以预定义 72 小时，保留真实间隔的比例。缺失特征由 mask 标记，零仅是存储占位，不能当成真实观测。重复时间戳合并同一特征的均值。

插值：对每名患者随机保留约 50% 的实际观测时刻供识别模型使用，在原始完整观测上评分。ODE-RNN 按论文先以自回归任务和 scheduled sampling 训练，在评估时仅消费允许的条件观测。验证与测试的条件子集固定，训练条件子集重新采样。

外推：每名患者按排序后的观测序列分成前 `floor(N/2)` 条与其余条。将该患者最后一个历史观测平移到零，前半部分时间非正、后半部分时间为正，再构建并集。这种平移对自治 ODE 保持时间间隔不变，能让不同长度患者的后验锚点一致；不使用未来数值构造编码输入。ODE-RNN 在各患者实际预测时刻消费上一预测，其他患者的并集时刻不触发更新。预测时间安排视为已知，与论文条件于观测时间的基础模型一致。

分类：`adverse_event` 不是论文的死亡率标签，只用于本地联合学习演示。分类脚本使用全观测插值条件、BCE 权重 100；报告 AUROC/AUPRC，不校准阈值。主插值/外推实验默认分类权重 0，故不报告未经训练的分类器指标。

局部默认尺寸采用 PhysioNet 实验量级：生成/独立 ODE-RNN 状态 20，识别状态 40，ODE 三个 50 单元 Tanh 隐藏层，线性观测解码器；batch size=10，Adam lr=0.001，梯度范数裁剪至 10。较小 batch 和学习率是当前 100 人数据上的明确配置，不宣称复刻论文某个特定数据集的全部超参数。保存配置文件包含每次运行的真实取值。

实现本任务要求的两种**基础模式**，不包含正文 §3.3 的可选 Poisson 观测时间联合似然扩展。本地实验条件于给定时间戳。

## 验证与可复现性

```bash
source ~/miniforge3/etc/profile.d/conda.sh
conda activate ode
python -m unittest discover -s tests -v
EPOCHS=20 bash scripts/run_paper_experiments.sh
EPOCHS=20 bash scripts/run_paper_classification.sh
```

26 项单元测试覆盖解析 ODE 解、反向积分、可训练参数梯度、GRU 门公式、编码方向、后验采样分布、ELBO/高斯似然对照 PyTorch 分布、特征级屏蔽、NaN 占位、无观测跳变跳过、批样本独立性、因果性、解码时间锚点、重复查询映射、锚点之前与之后的双向查询、单点序列、递归外推、模型保存载入、两种模型的小样本过拟合，以及患者划分、训练集归一化和外推条件隔离。

这些测试提供对关键公式与行为的回归保障，不能构成“所有可能输入均无错误”的数学证明。连续高斯密度可以大于 1，因此负对数似然乃至负 ELBO 的数值为负不代表实现出错。训练脚本检查非有限损失与梯度。验证 MSE 选模后恢复最佳权重，随后测试；独立 `src.evaluate` 重新构造划分、检查归一化参数与患者元信息并重放评估。固定 CPU 单线程、seed、评估条件子集及后验随机样本；GPU 或不同库版本可能产生数值差异。`reproduction/check_results.py` 还自动核验完整训练轮数、最佳验证轮次、检查点元信息和独立测试评估的一致性。
