# ADNI与MIMIC采样间隔均匀度比较

## 1. 结论

两套数据都属于不规则采样，但不规则性的表现层次不同：

- 在模型实际读取的**患者联合时间轴**上，ADNI明显比MIMIC更不均匀。ADNI患者内间隔CV中位数为0.515，MIMIC为0.391；对应Gini中位数为0.268和0.148。
- 在排除静态背景后、按**患者—动态字段自己的观测时间轴**计算时，MIMIC反而略更不均匀：CV中位数为0.432，ADNI为0.353；Gini中位数为0.213和0.168。
- 原因是MIMIC中的心率、血压等高频生命体征不断产生联合时间节点，使患者整体时间轴接近逐小时规则；但化验、血气、体温和GCS仍按临床需要异步测量。ADNI的不同认知量表常在同一次计划随访中共同测量，所以字段级时间轴相对更同步；患者随访本身则存在半年、一年、多年等不同间隔。

因此不能简单写成“MIMIC规则、ADNI不规则”。更准确的说法是：**ADNI具有更强的访视级时间不规则性；MIMIC具有较密集的近小时级联合时间轴，但保留明显的字段级异步和不规则采样。**

## 2. 数据与定义

统计直接读取当前五模型比较所使用的数据文件：

| 数据 | 文件 | SHA256 | 患者 | 动态/总字段 |
|---|---|---|---:|---:|
| ADNI | `paper_odeae/cache/local_available.pkl` | `9606b09c…f165de7` | 2,900 | 34/40 |
| MIMIC-IV 3.1 | `/data/MIMIC/derived/latentode_iv31/dataset.pkl` | `67944547…491897` | 30,702 | 30/31 |

当前预处理并未保留原始连续时间戳：ADNI先聚合到日历季度，MIMIC先聚合到小时，随后都删除完全没有动态观测的时间格。因此本文量化的是**模型实际看到的离散时间轴**，其不规则程度通常低于未经聚合的原始事件流。

主要无量纲指标如下：

- **患者内间隔CV：** 相邻间隔的总体标准差除以均值；0表示完全等间隔，越大越不均匀。
- **患者内间隔Gini：** 相邻间隔的不平等程度；0表示完全等间隔。
- **相邻间隔变化：** \(|d_{i+1}-d_i|/(d_{i+1}+d_i)\)，取患者内均值，范围为0到1。
- 患者级和患者—字段级变异指标只纳入至少有三个时间点、即至少两个间隔的序列。

字段级统计排除了ADNI的性别、年龄、婚姻、教育、利手和APOE4，以及MIMIC的性别，因为这些是静态背景，不是重复采样的动态指标。

## 3. 联合时间轴比较

联合时间轴在某个时间格只要有任一动态字段，就保留该节点。这正是当前模型接收的序列时间轴。

| 指标 | ADNI | MIMIC |
|---|---:|---:|
| 患者数 | 2,900 | 30,702 |
| 时间节点数 | 17,165 | 1,181,642 |
| 相邻间隔数 | 14,265 | 1,150,940 |
| 每患者节点数，中位数 [Q1, Q3] | 5 [3, 8] | 39 [35, 42] |
| 随访跨度，中位数 [Q1, Q3] | 3.00 [1.25, 6.75] 年 | 47 [46, 47] 小时 |
| 相邻间隔，中位数 [Q1, Q3] | 0.75 [0.25, 1.00] 年 | 1 [1, 1] 小时 |
| 相邻间隔，P90 / P95 / 最大值 | 1.75 / 2.25 / 9.00 年 | 2 / 2 / 19 小时 |
| 全部间隔的CV | 0.846 | 0.460 |
| 患者内CV，中位数 [Q1, Q3] | 0.515 [0.355, 0.656] | 0.391 [0.308, 0.471] |
| 患者内Gini，中位数 [Q1, Q3] | 0.268 [0.169, 0.338] | 0.148 [0.098, 0.199] |
| 相邻间隔变化，中位数 | 0.237 | 0.108 |
| 患者内最大/最小间隔比，中位数 | 4.02 | 3.00 |
| 所有间隔完全相等的患者 | 6.80% | 1.03% |

最后一行不能单独用于判断谁更规则：MIMIC每名患者通常有约39个节点，只要其中缺一个小时就不再“完全相等”；ADNI节点更少，偶然全部等间隔更容易。CV、Gini和相邻间隔变化对不同序列长度更有解释力，它们一致指向ADNI联合时间轴更不规则。

### 3.1 基础网格上的间隔组成

ADNI的基础步长为一个季度，MIMIC为一个小时：

| 基础网格间隔 | ADNI占比 | MIMIC占比 |
|---|---:|---:|
| 1个基础步长 | 25.21% | 81.24% |
| 2个基础步长 | 20.90% | 14.99% |
| 3个基础步长 | 7.68% | 2.84% |
| 4个基础步长 | 27.16% | 0.68% |
| 更长 | 19.05% | 0.25% |

ADNI的众数是4个季度，即约一年，但只占27.16%；四分之一间隔约为一个季度，另有大量半年、九个月和多年间隔。MIMIC的众数是1小时，占81.24%，说明联合时间轴大部分接近逐小时连续。

这里“超过一个季度”不等于漏访，因为ADNI方案本来就可能安排半年或年度随访；该表只描述时间间隔组成，不评价方案依从性。

## 4. 单个动态字段的采样间隔

联合时间轴会掩盖不同字段并非同时测量。对每个患者—动态字段单独提取观测时间后得到：

| 指标 | ADNI | MIMIC |
|---|---:|---:|
| 有至少2次观测的患者—字段对 | 62,131 | 824,389 |
| 字段级相邻间隔数 | 249,962 | 9,121,710 |
| 字段级间隔，中位数 [Q1, Q3] | 1.00 [0.50, 1.25] 年 | 2 [1, 3] 小时 |
| 字段级间隔P90 / P95 | 2.00 / 2.51 年 | 7 / 12 小时 |
| 患者—字段内CV，中位数 [Q1, Q3] | 0.353 [0.253, 0.473] | 0.432 [0.319, 0.553] |
| 患者—字段内Gini，中位数 [Q1, Q3] | 0.168 [0.126, 0.250] | 0.213 [0.153, 0.277] |
| 字段观测间隔完全相等的患者—字段对 | 13.08% | 0.61% |

MIMIC字段级差异也很大：心率、血压和血氧的中位间隔为1小时；体温、FiO2、血气和GCS约3小时；乳酸4小时、葡萄糖6小时；多数常规化验约7至10小时，体重约16小时。ADNI的MMSE、CDR、ADAS等多数认知量表中位间隔约1年，部分数字广度/语义流畅性项目约半年，CSF和PET约2年。

## 5. 对论文表述和建模的含义

1. **两套数据都支持irregular-sampling任务设定。** ADNI的连续时间建模主要用于跨度差异很大的长期随访；MIMIC则主要用于处理短期高频但字段异步的临床事件。
2. **MIMIC不能仅因使用小时网格就称为regular sampling。** 小时是聚合分辨率，不代表每小时、每个字段都被观测；空小时被删除，字段掩码也高度不同步。
3. **联合时间轴和字段时间轴应分别报告。** 只报告MIMIC联合间隔会得到“81.24%为1小时”的近规则印象，但患者—字段CV反而高于ADNI。
4. **跨数据集不应直接比较物理间隔大小。** 年和小时没有可比性，因此数据集间结论主要依据CV、Gini等无量纲指标。

可复现统计脚本为 [`scripts/analyze_sampling_irregularity.py`](../scripts/analyze_sampling_irregularity.py)。本分析只执行CPU数据读取和描述统计，没有训练、验证、评估或诊断任何模型。
