# latent2x both 在 CausalMed 上的反事实推演

## 1. 从事实治疗记录学习，再回答干预问题

CausalMed为每位患者提供不规则时间检查、静态资料和治疗区间。训练患者与验证患者各自只有一条事实轨迹。测试患者提供分叉前的历史，以及分叉后的检查日程和五种干预规则。

本实验先从事实记录学习“患者状态怎样变化、治疗怎样影响后续状态”。然后，把同一位测试患者的历史状态复制五份，分别执行五种策略，比较未来结果。

本轮仅使用 **γ=1**，比较latent2x both与ODE-AE。前者在物理GPU 3继续训练，后者在空闲的物理GPU 1单卡训练和推演。当前进度、最终指标及平行病例图见[γ=1模型比较](../outputs/gamma1_model_comparison/summary.md)。

完整评分后的真实与预测曲线、个体治疗效应散点及风险—治疗闭环图，会自动写入[病例分析](../outputs/latent2x_both_cuda3/analysis.zh-CN.md)。

## 2. 使用哪些数据

### 2.1 本轮使用γ=1总体

使用已交付的 `CausalMed/outputs/level3_suite/gamma_1/public/`。

| 内容 | 每组数量或定义 |
|---|---|
| 训练患者 | 10,000 |
| 验证患者 | 2,000 |
| 测试患者 | 2,000 |
| 观察年限 | 0至8年 |
| 观测字段 | Y、X1、X2 |
| 静态资料 | c |
| 治疗 | 0或1，记录每个区间的起止时间 |
| 测试分叉 | 第一次时间达到3年的实际检查，包含这次观测 |
| 干预策略 | Never、Always、Delayed、Aggressive、Conservative |

gamma表示事实治疗分配中的混杂强度。本轮固定为1，两种模型均从seed 0独立初始化。其余三档保留在数据目录中，当前不安排训练。

### 2.2 训练与测试分别能读取什么

训练和验证读取公开事实检查与治疗路径。测试读取分叉前的观测、已完成的治疗区间、未来检查时刻和策略规则。

每个模型进程运行在独立文件系统命名空间中，只挂载公开数据、模型源码、当前输出和SwanLab日志。反事实真值由独立评分进程读取。流程为：

**公开事实训练 → 选择检查点 → 写完反事实预测与治疗区间 → 固定文件SHA256 → 配对真值评分。**

数据加载使用已交付的最小 `causalmed_client`。三项观测使用训练集均值和标准差归一化，静态c也只使用训练患者拟合变换。

## 3. latent2x both怎样接入治疗

### 3.1 保留四个核心模块

| 模块 | 本次结构 | 作用 |
|---|---|---|
| INIT | 1 → 159 → 28 | 根据静态c建立起点 |
| 共享ODE | 28 → 188 → 28 | 连续推进患者状态 |
| UPDATE | 38 → 159 → 28 | 接收观测事件和治疗条件 |
| DECODER | 28 → 159 → 3 | 输出Y、X1、X2 |

隐藏层使用Tanh，输出层为线性层。共享ODE仍使用自适应Tsit5，`rtol=1e-4`、`atol=1e-6`，时间单位为年。总参数量为 **31,314**。

潜在维度、各网络宽度及共享向量场沿用latent2x both。输入输出层按三个观测字段和干预事件适配，INIT的单个输入改为本数据公开的静态c。

### 3.2 UPDATE接收一个10维事件向量

事件向量由以下部分组成：

| 内容 | 维度 |
|---|---:|
| 当前三项观测，缺失位置置0 | 3 |
| 三项观测掩码 | 3 |
| 当前治疗0/1的独热编码 | 2 |
| 观测事件 / 动作事件的独热编码 | 2 |

它与28维状态拼接，形成38维UPDATE输入。

在历史检查时刻，先用ODE演化到该时刻，再读取观测，形成新的患者状态。当前检查决定的治疗在观测之后处理。

### 3.3 治疗切换怎样改变状态位置

记 \(H_\phi(z,a)\) 为UPDATE在“动作事件”条件下、接收治疗 \(a\) 时的输出。这时观测值和观测掩码均为0。

从旧治疗 \(a^-\) 切换到新治疗 \(a^+\) 时：

\[
\boxed{
z^+=z^-+H_\phi(z^-,a^+)-H_\phi(z^-,a^-)
}
\]

这相当于用同一个UPDATE比较两个治疗条件，再把差值作为状态的位移。

这种写法有两个直接性质：

- 治疗保持不变时，两个输出相同，位移为0。
- 治疗切换后，患者进入新的潜在位置，随后沿共享ODE产生新的演化轨迹。

治疗状态通过潜在位置持续影响后续演化。未来只有治疗切换执行这一动作校正，普通查询时刻继续推进ODE。

### 3.4 怎样重构含治疗历史的过去

历史编码结束时，保存最后一次观测更新后的状态。这个状态位于该次检查的治疗决策之前。

向过去重构时，按时间反向积分；遇到已经发生的历史治疗切换，就把新旧治疗标签对调，用同一UPDATE计算反向状态校正，再继续积分。这样，历史重构也沿着已知治疗条件的变化顺序进行。

## 4. 两种模型如何训练

### ODE-AE如何使用相同干预任务

ODE-AE保留原有的6维Gaussian潜在状态、12维反向编码状态、16宽网络，以及彼此独立的编码ODE和生成ODE。INIT仍读取标准化静态c，反向UPDATE读取相同的三项观测、掩码和治疗条件。

后验位于首次历史检查处。训练时从后验采样，由生成ODE按已知事实治疗路径向前生成；测试时使用后验均值。反事实分叉前，先从首次检查处沿已知历史治疗重放到截止时刻，再从该状态执行五种未来策略。

编码状态为12维、生成状态为6维，因此生成阶段使用一个独立的 `6+2 → 16 → 6` 治疗校正模块。它同样用新旧治疗条件输出之差形成残差位移。模型合计 **1,843参数**。

ODE-AE的目标为三字段标准化MSE＋1×Gaussian后验KL＋0.02×两个ODE的参数L2。数据、归一化、训练截止规则、优化预算、验证选模和测试策略均沿用本页协议。两种模型的参数量及正则分别列在比较表中。

### 4.1 从一位患者构造一个训练任务

下面先说明latent2x both的轨迹生成。ODE-AE使用相同的历史截止点与标签，从上段介绍的首次检查后验出发向前生成。

每轮为每位训练患者选一个历史截止点：候选为首次达到1、2、3、4年的实际检查。选择由seed、轮次和患者编号共同确定。

模型读取这段历史，得到截止状态，然后：

1. 沿过去的记录时间重构历史，并处理已知的反向治疗切换。
2. 沿未来的事实治疗路径推演，在下一次治疗决定之前预测该次观测。
3. 在有效观测上计算误差。

未来真实观测承担监督标签。未来事实治疗作为给定的干预路径，按发生顺序输入；某次检查后才决定的治疗，从该检查之后开始影响预测。

### 4.2 保留both版本的损失

\[
L=L_{\mathrm{MSE}}
+0.02L_{\mathrm{ODE\text{-}L2}}
+0.01L_{\mathrm{prior}}
+0.01L_{\mathrm{jac}}.
\]

| 损失 | 本次计算方式 |
|---|---|
| 主MSE | 三个字段在有效目标上分别取平均，再求和；同时覆盖历史重构和事实未来预测 |
| weak prior | 从第二条历史记录起，在读取当前观测前解码，与真实观测比较 |
| Jacobian | 在生成轨迹的有效状态上，对完整28×28导数矩阵的784项平方求和，再按状态取均值 |
| ODE参数L2 | 共享向量场参数平方和，计一次 |

Jacobian采样位置停止梯度，向量场参数保留梯度。输入dropout为0.1，监督继续使用原始观测掩码。

### 4.3 用事实验证轨迹选择检查点

验证截止点与测试一致，固定为首次达到3年的实际检查。模型根据验证患者的公开事实治疗路径重构和预测，整体三字段标准化误差最小时保存检查点。

训练设置为Adam、学习率0.003、按`0.97^(step/2000)`衰减、batch 128、梯度范数上限10。最多300轮，至少50轮，验证整体误差连续40轮未改善时早停。

训练结束后重新载入最佳检查点，核对验证分数，再固定参数进行反事实推演。

## 5. 如何生成五条反事实轨迹

### 5.1 先得到共同的分叉状态

对每位测试患者，只读取公开历史，直到包含分叉检查。保存观测更新后的状态和上一段治疗。

该状态复制五份，静态资料、历史和未来检查日程相同。五条分支分别执行不同策略。

### 5.2 在规定的未来检查时刻选择动作

| 策略 | 动作规则 |
|---|---|
| Never | 分叉后始终不治疗 |
| Always | 分叉后始终治疗 |
| Delayed | 分叉1年后第一次实际检查开始治疗，之后持续 |
| Aggressive | 该分支当前X2超过公开训练阈值q50时治疗 |
| Conservative | 该分支当前X2超过公开训练阈值q80时治疗 |

分叉时，X2已经包含在公开历史中，因此使用这次真实观测作初次决策。之后每次检查只给出时间，模型先用ODE演化并预测X2，再根据该分支自己的预测选择动作。

例如，一条分支预测风险超过q50，就开始治疗；治疗造成的状态位移会改变之后的风险轨迹，下一次检查再据此决定是否继续治疗。这形成“状态 → 风险预测 → 动作 → 新状态”的闭环。

### 5.3 保存轨迹和精确治疗区间

每条分支预测公开逐月网格上的Y、X1、X2，并覆盖精确的1、2、3年终点和8年边界。查询与治疗决策重合时，先输出该时刻的指标，再应用新的动作。

同时保存模型自身产生的治疗区间。策略成本和效用使用这些区间计算治疗年数。

## 6. 怎样评价反事实能力

### 6.1 轨迹与终点预测

使用数据集已有评分器，计算预测Y与同一患者、同一策略的无噪声反事实Y之间的CF-RMSE。分别报告全轨迹、1年、2年、3年，以及每个策略的误差。

### 6.2 个体和人群治疗效应

以Never为参照，计算其他策略的治疗效应：

\[
\tau_i^{(p)}=Y_i^{(p)}-Y_i^{(\mathrm{Never})}.
\]

报告个体效应误差sqrt(PEHE)、人群平均效应误差ATE Error，以及真实和预测ATE。

### 6.3 策略选择

使用公开固定成本3，效用为：

\[
U=Y-3\times\text{治疗年数}.
\]

模型根据自己预测的五种效用选择策略。随后用配对真值计算Policy Regret和最优策略准确率。

### 6.4 关闭未来动作输入作对照

同一检查点额外生成一组推演：历史编码保持相同，分叉后的动作校正关闭。策略规则仍正常执行并记录治疗区间，未来状态只沿原ODE继续演化。

这组对照中，五条分支的预测结局相同。比较两组CF-RMSE和治疗效应误差，可以直接观察未来动作信息是否改善了反事实预测。

## 7. 运行与查看结果

在项目根目录执行：

```bash
# latent2x both，物理GPU 3，仅gamma=1。
bash scripts/run_causalmed_latent2x_both.sh

# ODE-AE，物理GPU 1，仅gamma=1。
bash scripts/run_causalmed_odeae.sh
```

每个任务依次完成CUDA检查、小规模训练与推演、正式训练、完整测试预测及独立评分。两个模型各占一张卡，进程内部的逻辑`cuda:0`分别映射到所分配的物理GPU 3或GPU 1。

latent2x both输出位于 `CausalMed/outputs/latent2x_both_cuda3/`，ODE-AE输出位于 `CausalMed/outputs/ode_ae_gamma1_cuda1/`，统一比较位于 `CausalMed/outputs/gamma1_model_comparison/`。

| 文件或目录 | 内容 |
|---|---|
| `summary.md` | 实时进度、事实验证及反事实结果表 |
| `manifest.json` | 本轮gamma=1配置、公开文件和模型源码SHA256 |
| `model_source/` | 模型命名空间使用的源码，不含生成器和评分器 |
| `gamma_*/checks/` | CUDA梯度、时间单位、治疗时序及未来信息隔离检查 |
| `gamma_*/smoke/` | 小规模完整训练与五策略推演 |
| `gamma_*/model/` | 正式检查点、逐轮日志、硬件和隔离记录 |
| `gamma_*/model/with_actions/` | 正式动作条件推演、模型治疗区间及文件校验值 |
| `gamma_*/model/action_off/` | 同检查点关闭未来动作的推演 |
| `gamma_*/evaluation/` | 独立评分进程输出的指标 |

CUDA检查已覆盖：改变未来观测不影响预测；分叉后的治疗决定不进入历史状态；未来查询点之后的动作不改变已经生成的未来预测；治疗不变时状态位移为零；延迟策略与严格风险阈值按公开规则执行；全部参数梯度有限。

训练接入SwanLab。`best.pt`用于最终推演，`last.pt`保存最近完整轮次，入口重启时可继续未完成任务。
