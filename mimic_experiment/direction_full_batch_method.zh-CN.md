## 2. 两组共用哪些网络

先把一名患者的记录分成已知历史和待预测未来。已知历史的第一次记录时间记为 $t_0$，最后一次记为 $t_c$。测试时读取前24小时内的记录，$t_c$ 是其中最后一条实际记录的时间；后续记录作为预测目标。

两组都用一个28维状态表示患者。遇到已知检查时，UPDATE把检查信息写入状态；两次检查之间，状态沿共享ODE连续演化；Decoder把状态转换成临床指标。

| 网络 | 输入与输出 | 隐藏宽度 | 参数量 | 作用 |
|---|---|---:|---:|---|
| INIT | 年龄 → 28维状态 | 159 | 4,798 | 建立读取历史前的初始状态 |
| UPDATE | 28维状态＋44维观测输入 → 28维状态 | 159 | 16,087 | 吸收当前历史记录 |
| 共享ODE | 28维状态 → 28维速度 | 188 | 10,744 | 描述连续时间变化 |
| Decoder | 28维状态 → 44维输出 | 159 | 11,651 | 输出数值预测与类别logits |
| 合计 | | | **43,280** | 总参数量与可训练参数量相同 |

各网络都是“线性层 → Tanh → 线性层”。MIMIC的31个原始字段展开为44维输入与输出，其中类别字段用one-hot表示。缺失输入字段按掩码置零，训练时再对历史输入施加0.1 dropout。两组在每条有效历史记录处执行UPDATE，padding位置不更新。

**每个模型内部，历史吸收和自由生成共用一个速度场 $f_\theta$。** 两个实验各自训练自己的网络；相同seed使初始权重一致，训练后得到各自的参数。

下面用三个符号描述计算过程：

- $\Phi_{\Delta t}(z)$：从状态 $z$ 出发，沿同一个ODE积分 $\Delta t$。正时间间隔表示向未来演化，负时间间隔表示向过去演化。
- $U(z,y_k)$：用第 $k$ 条已知记录执行UPDATE。
- $g(z)$：Decoder在状态 $z$ 处输出的临床指标预测。

### 2.1 两组怎样使用年龄

当前这两组都使用**最后一条已知历史记录处的患者年龄**：

\[
a_c=a_{\mathrm{入ICU}}+\frac{t_c}{8766},
\qquad
h_{\mathrm{init}}=\operatorname{INIT}(a_c/100).
\]

ODE时钟的单位是小时，年龄的单位是年。年龄通过INIT进入状态，检查之间的时间差则用于ODE积分。

两组将这个初始状态放在不同的时间位置：正向组从 $t_0$ 开始读取，反向组从 $t_c$ 开始读取。两组当前都沿用上述 $a_c$ 初始化方式。

## 3. 两组怎样吸收已知历史

### 3.1 正向组：从最早记录逐次吸收到历史截止点

正向组按 $t_0,t_1,\ldots,t_c$ 的顺序处理历史：

1. 在首次记录处放置INIT状态，并用首次记录执行UPDATE。
2. 沿ODE向未来演化到下一条记录的时间。
3. 在UPDATE前读出预测，供weak_prior监督使用。
4. 吸收该条记录，继续处理下一条。

后续每一步可以写成：

\[
h_k^- = \Phi_{t_k-t_{k-1}}(h_{k-1}^+),
\qquad
h_k^+ = U(h_k^-,y_k).
\]

其中“−”表示当前记录进入UPDATE之前，“＋”表示之后。读取完整段历史后，得到截止点状态 $h_c^+$，主重建和未来预测都以它为起点。

### 3.2 反向组：从最近记录逐次吸收到首次历史记录

反向组按 $t_c,t_{c-1},\ldots,t_0$ 的顺序处理同一段已知历史：

1. 在最后一条已知记录处放置INIT状态，并吸收这条记录。
2. 沿ODE向过去演化到前一条记录的时间。
3. 用前一条记录执行UPDATE。
4. 重复上述过程，直到吸收首次历史记录。

以 $q_k$ 表示读取完第 $k$ 条记录后的状态：

\[
q_c=U(h_{\mathrm{init}},y_c),
\qquad
q_k=U\!\left(\Phi_{t_k-t_{k+1}}(q_{k+1}),y_k\right).
\]

最终得到首次记录处的状态 $q_0$。它已经汇总了**整段已知历史**，用于估计患者在首次记录时的状态。每一步所吸收的记录都来自已知历史区间。

UPDATE是非线性的观测校正。改变校正顺序，同时改变最终状态所在的时间位置，会形成不同的生成起点和自由演化轨迹。

## 4. 两组怎样重建历史、预测未来

历史吸收完成后，两组都进入自由生成阶段。这个阶段只有ODE与Decoder，**历史目标和未来目标均不再进入UPDATE**。

### 4.1 正向组：从截止点分别向过去和未来生成

正向组从 $h_c^+$ 出发，对任意目标时刻 $t$ 生成：

\[
\hat y_{\mathrm{正向}}(t)
=g\!\left(\Phi_{t-t_c}(h_c^+)\right).
\]

- **历史重建**：从 $t_c$ 向过去积分，在历史检查时间读出指标。
- **未来预测**：重新从 $h_c^+$ 出发，向未来积分，在未来检查时间读出指标。

代码为这两个任务分别保留同一个截止点状态作为起点。未来预测直接从该状态开始，历史重建路径的数值积分结果留在历史任务中。

### 4.2 反向组：从首次记录一直向未来生成

反向组从 $q_0$ 出发，对任意目标时刻 $t$ 生成：

\[
\hat y_{\mathrm{反向}}(t)
=g\!\left(\Phi_{t-t_0}(q_0)\right).
\]

这条轨迹先经过历史检查时间，产生历史重建；随后经过历史截止点，继续产生未来预测。经过已知历史检查时，也只读出预测。

因此，反向组到达历史截止点时使用的是自由ODE生成的状态 $\Phi_{t_c-t_0}(q_0)$。正向组使用的截止点状态 $h_c^+$ 则刚刚吸收了最后一条历史记录。

| 环节 | 正向ODE组 | 反向共享ODE组 |
|---|---|---|
| 主历史读取顺序 | 最早记录 → 最近记录 | 最近记录 → 最早记录 |
| 读取时ODE的时间方向 | 向未来，每次到达历史记录后UPDATE | 向过去，每次到达历史记录后UPDATE |
| 读取完成后状态的位置 | 最后一条历史记录处 | 第一条历史记录处 |
| 主历史重建 | 从历史截止点向过去自由积分 | 从首次记录向未来自由积分 |
| 未来预测 | 从截止点的观测校正状态向未来积分 | 从首次记录自由演化，经过截止点后继续向未来积分 |
| 主生成阶段的UPDATE | 无 | 无 |
| 主数据损失要求 | 截止点状态同时支持向过去重建、向未来预测 | 首次记录状态支持一条向未来的轨迹解释全部历史与未来 |

## 5. 损失相同的部分，以及计算路径的区别

两组的总损失均为：

\[
\mathcal L
=\mathcal L_{\mathrm{main,MSE}}
+\mathcal L_{\mathrm{main,CE}}
+0.01\left(\mathcal L_{\mathrm{prior,MSE}}+\mathcal L_{\mathrm{prior,CE}}\right)
+0.01\mathcal L_{\mathrm{Jacobian}}
+0.02\mathcal L_{\mathrm{ODE\ L2}}.
\]

### 5.1 主数据损失用各自的自由生成轨迹计算

两组都对历史和未来的真实目标计算主损失。数值字段使用训练集min-max归一化后的MSE，类别字段使用交叉熵。每个字段在当前batch内按有效观测求均值，再对字段求和；缺失字段不计入损失。

目标记录与权重相同，预测状态来自第4节所述的两种生成路径。主历史损失因而分别约束“截止点向过去重建”和“首次记录向未来重建”。

### 5.2 weak_prior都监督朝未来的UPDATE前预测

正向组在主历史吸收过程中已经得到每次UPDATE前的预测，直接用这些预测计算weak_prior。监督范围为第二条至最后一条历史记录。

**反向组会额外读取一次历史，专门提供weak_prior预测。** 这次从相同年龄的INIT状态重新开始，按最早到最近的顺序，用同一套共享ODE、UPDATE和Decoder处理历史。输入记录与输入掩码也相同，每次在UPDATE前读出预测。

辅助读取的最终状态不用于主生成。反向组的主重建与未来预测仍从反向读取所得的 $q_0$ 开始。weak_prior的梯度则通过这条辅助路径更新共同的网络参数。

| 训练计算路径 | 正向ODE组 | 反向共享ODE组 |
|---|---|---|
| 主数据损失 | 朝未来读取历史，再从截止点生成历史与未来 | 朝过去读取历史，再从首次记录生成历史与未来 |
| weak_prior | 复用主读取过程中的UPDATE前预测 | 额外朝未来读取历史，取得UPDATE前预测 |
| 历史吸收次数 | 一次 | 两次：一次主读取、一次辅助读取 |

两组参数量相同；反向组多进行一次历史吸收，计算量也随之增加。

### 5.3 Jacobian和L2怎样作用

Jacobian正则为各有效生成状态上 $\|\partial f_\theta(z)/\partial z\|_F^2$ 的平均。正向组在“截止点向过去、向未来”生成的状态上采样，反向组在“首次记录向未来”生成的状态上采样。采样位置detach，这一项直接约束速度场参数。

ODE L2对共享速度场的权重和偏置平方求和，单个共享网络只计一次。两组都是确定性状态模型，实际KL项为0。

验证选模只用主数据误差MSE＋交叉熵。weak_prior、Jacobian和L2作为训练目标的组成部分，另外记录。

## 6. 用同一条患者时间线走一遍

下面是一条示意记录：患者入ICU时65岁，在第1、6、12、24小时有已知检查；第36、48小时是待预测检查。两组INIT都使用最后已知检查处的年龄 $65+24/8766$。

| 阶段 | 正向ODE组 | 反向共享ODE组 |
|---|---|---|
| 主历史吸收的第一步 | 在1小时处INIT，吸收1小时记录 | 在24小时处INIT，吸收24小时记录 |
| 第二步 | ODE向未来演化5小时，吸收6小时记录 | ODE向过去演化12小时，吸收12小时记录 |
| 第三步 | ODE向未来演化6小时，吸收12小时记录 | ODE向过去演化6小时，吸收6小时记录 |
| 第四步 | ODE向未来演化12小时，吸收24小时记录，得到 $h_{24}^+$ | ODE向过去演化5小时，吸收1小时记录，得到 $q_1$ |
| 主历史重建 | 从 $h_{24}^+$ 读出24小时，再向过去积分到12、6、1小时 | 从 $q_1$ 读出1小时，再向未来积分到6、12、24小时 |
| 未来预测 | 从 $h_{24}^+$ 重新出发，向未来积分到36、48小时 | 从 $q_1$ 生成的轨迹经过24小时后，继续到36、48小时 |
| weak_prior监督 | 主历史吸收时，预测6、12、24小时的记录，再分别UPDATE | 另外按1→6→12→24小时吸收，预测6、12、24小时后再UPDATE |

这个例子中，两组主生成阶段都要重建4条历史记录、预测2条未来记录。正向组的主生成起点位于24小时，反向组位于1小时；反向组的weak_prior再通过一条独立的朝未来历史读取路径提供监督。

上述过程对应本实验冻结实现中的[正向读取与生成](source_snapshot/paper_odeae/models.py)、[反向读取及辅助weak_prior路径](source_snapshot/paper_odeae/history_encoders.py)、[MIMIC年龄初始化](source_snapshot/mimic_experiment/data.py)和[损失计算](source_snapshot/mimic_experiment/train_full_batch.py)。
