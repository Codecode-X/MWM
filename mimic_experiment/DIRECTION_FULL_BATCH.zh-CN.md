# MIMIC：正向与反向共享ODE的单卡整批训练对照

## 1. 本轮比较什么

本轮将latent2x both（正向ODE）和反向共享ODE都从seed 0重新训练。两组各用一张4090，**每个训练步骤直接处理完整128人batch，无梯度累积**。

旧注意力组及旧反向组已经停止。它们的最佳检查点、恢复检查点、逐轮指标和SwanLab记录均保留在原目录；本轮使用新的输出目录，重新初始化全部模型权重。

[实时结果](results/direction_full_batch_cuda/summary.md)并列展示两组新单卡结果与历史四卡结果。方向收益由两组新单卡结果计算。

正向后期失稳与反向后期改善的逐轮证据、CUDA轨迹敏感性诊断，见[训练稳定性分析](results/direction_full_batch_cuda/instability_analysis/report.zh-CN.md)。

## 2. 保持哪些条件一致

| 设置 | 正向latent2x both | 反向共享ODE |
|---|---|---|
| 物理GPU | 3 | 2 |
| 训练方式 | 单卡 | 单卡 |
| 完整训练batch | 128 | 128 |
| 梯度累积次数 | 1 | 1 |
| 每步前向 / 反向 / 参数更新次数 | 1 / 1 / 1 | 1 / 1 / 1 |
| 状态维度 / 总参数量 | 28 / 43,280 | 28 / 43,280 |
| INIT / UPDATE / DECODER隐藏宽度 | 159 / 159 / 159 | 159 / 159 / 159 |
| 共享ODE隐藏宽度 | 188 | 188 |
| 随机种子 | 0 | 0 |
| Adam初始学习率 | 0.003 | 0.003 |
| 学习率衰减 | 0.97^(step/2000) | 相同 |
| 输入观测dropout | 0.1 | 0.1 |
| 梯度范数上限 | 10 | 10 |
| 最多 / 最少轮次 | 300 / 50 | 300 / 50 |
| 早停耐心 | 40轮 | 40轮 |

两组采用同一个整批训练函数。相同seed下，所有初始参数逐项一致；每轮使用相同的患者顺序、历史截止点和dropout采样规则。

每步先将整批数据放到本卡，计算整批损失，再反向传播一次。最后不足128人的批次按实际有效观测数和人数计算。

## 3. 唯一的主流程差异

正向组按时间从前往后读取历史，在最后一次已知检查处得到状态，再从该状态重构过去、预测未来。

反向组用相同的UPDATE和同一个速度场，从后往前读取历史，在首次检查处得到状态，再从起点沿同一个ODE向前生成完整轨迹。

两组均为确定性状态，保留相同年龄初始化。编码方向及随之对应的生成起点构成本轮比较因素。

## 4. 相同的损失和评测

\[
L=L_{\mathrm{MSE}}+L_{\mathrm{CE}}+0.01L_{\mathrm{prior}}+0.01L_{\mathrm{jac}}+0.02L_{\mathrm{ODE\text{-}L2}}.
\]

数值和类别损失在整批有效标签上按字段取平均。weak prior继续预测尚未读入的下一次历史检查。反向组通过同参数辅助正向扫描计算这项监督，辅助状态不作为主生成起点。Jacobian对整批有效生成状态计算完整28×28导数矩阵平方范数，采样位置停止梯度。

数据仍为MIMIC-IV 3.1的chronology_v2缓存，训练21,517人、验证4,649人、测试4,536人。训练每位患者每轮选择6、12、18或24小时历史。主要验证与测试读取前24小时，预测到48小时，补充测试使用6小时和12小时历史。

验证与测试沿用共同评价器的固定32人查询批次及四份固定患者分片。它们只计算指标；训练的128人整批前向和反向不做分片。

两组按验证整体数据误差选择最佳检查点。完成后重新载入最佳检查点，核对验证分数，再运行完整测试，并核对患者数与有效观测数。

## 5. 检查与执行记录

预检查在CUDA上核对：相同配置、相同初始参数、相同患者与dropout、相同weak prior监督、未来信息隔离，以及完整128人batch的一次前向、一次反向和一次参数更新。

小规模训练也使用真实48小时序列和完整128人训练批次，以检查实际显存占用。正式训练记录实际batch大小、每轮前向和反向次数、优化步数及显存峰值；全部接入SwanLab。

模型与数据处理代码复制自旧反向实验的固定源码，新增两组共用同一个整批训练入口。源码散列、配置和来源保存在`manifest.json`。每组独立保存`best.pt`、`last.pt`、`history.json`、`metrics.json`、`hardware.json`和`swanlab.json`。

启动入口：

```bash
bash scripts/run_mimic_direction_full_batch.sh
```

输出目录：`mimic_experiment/results/direction_full_batch_cuda/`。
