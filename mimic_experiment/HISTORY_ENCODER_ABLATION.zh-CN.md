# MIMIC：历史读取方向与ODE编码作用的等参数消融

## 1. 从ADNI继续验证两个问题

[ADNI实验](../paper_odeae/results/latent2x_history_encoder_ablation/summary.md)已经完成正向ODE、反向共享ODE、注意力加时间编码三组比较。本轮把同样的两个消融接入MIMIC，研究这些设计在小时级生理记录中的作用。

参照使用已完成的MIMIC latent2x both。新增两组分别训练，结果持续写入[三组比较与跨数据集结果](results/history_encoder_ablation_cuda/summary.md)。

## 2. 三组怎样处理同一位患者

假设患者在入住ICU后第1、8、24小时有已知观测，需要预测第36小时。

| 模型 | 历史状态怎样形成 | 主生成怎样进行 |
|---|---|---|
| 正向参照 | 按1→8→24小时读取，每次先ODE推进再UPDATE | 从24小时状态向过去重构、向未来预测 |
| reverse_shared | 按24→8→1小时读取，用同一个ODE反向推进和相同UPDATE | 从1小时状态沿同一ODE向前生成，经过历史区间再预测未来 |
| attention_time | 将观测、实际经过小时和年龄INIT信息交给因果注意力 | 取24小时的注意力状态，再用原ODE重构和预测 |

反向组只改变主历史读取方式及对应的生成起点。它保留原有全部网络、隐藏宽度和共享速度场。

注意力组用直接编码替换ODE递推编码。历史状态由观测和时间形成，编码过程不调用ODE；主生成继续使用原来的ODE。因果掩码保证每个中间状态只读取截至该时刻的观测，患者自己的截止点掩码决定哪些记录可以进入历史。

## 3. 怎样保证相同参数预算

三组都是28维状态、**43,280个可训练参数**。

| 模块 | 正向参照 | reverse_shared | attention_time |
|---|---:|---:|---:|
| 年龄INIT：1→159→28 | 4,798 | 4,798 | 4,798 |
| 共享ODE：28→188→28 | 10,744 | 10,744 | 10,744 |
| 解码器：28→159→44 | 11,651 | 11,651 | 11,651 |
| 历史编码模块 | UPDATE，16,087 | 相同UPDATE，16,087 | 时间注意力，16,087 |
| 总计 | **43,280** | **43,280** | **43,280** |

注意力的16,087参数分为：

| 组成 | 结构 | 参数量 |
|---|---|---:|
| 观测嵌入 | 44→42→28，末层无偏置 | 3,066 |
| 自注意力 | 4头，每头7维 | 3,248 |
| 前馈网络 | 28→169→28 | 9,661 |
| 两个LayerNorm | 各28维 | 112 |
| 时间编码 | 固定正余弦，使用真实小时 | 0 |
| 合计 | 与原UPDATE相同 | **16,087** |

时间编码以患者首次观测为零点，14组周期覆盖0.5至48小时。年龄以年/100进入INIT，与ODE的小时钟分开。两组均保留与参照相同的共有网络初始权重。

## 4. 保持both的损失与训练任务

\[
L=L_{\mathrm{MSE}}+L_{\mathrm{CE}}
+0.01L_{\mathrm{prior}}+0.01L_{\mathrm{jac}}+0.02L_{\mathrm{ODE\text{-}L2}}.
\]

数据项覆盖历史重构和未来预测，在真实有效观测上按字段取平均。Jacobian继续计算共享速度场完整28×28导数矩阵的平方范数；采样位置停止梯度，向量场保留梯度。

weak prior继续评价“尚未读到下一次检查时的预测”。反向组用同参数辅助正向扫描计算这项监督，辅助状态不作为主生成起点。注意力组取截至上一次检查的注意力状态，沿共享ODE推进到下一次检查计算监督。ODE在注意力组中负责生成与校正前预测，历史注意力编码独立形成状态。

| 设置 | 与参照相同的取值 |
|---|---|
| 数据版本 | MIMIC-IV 3.1，chronology_v2缓存 |
| 训练 / 验证 / 测试患者 | 21,517 / 4,649 / 4,536 |
| 字段 | 31个原始字段，44维展开输出 |
| 归一化 | 训练集min-max |
| 训练历史长度 | 每位患者每轮从6、12、18、24小时选择 |
| 主要验证与测试 | 读取前24小时，预测到48小时 |
| 补充测试 | 仅6小时、12小时历史后预测到48小时 |
| 随机种子 / 有效batch | 0 / 128 |
| 优化器与学习率 | Adam，0.003，按0.97^(step/2000)衰减 |
| 输入dropout / 梯度上限 | 0.1 / 10 |
| ODE | Tsit5，rtol=1e-4，atol=1e-6 |
| 最多 / 最少轮次 | 300 / 50 |
| 选模与早停 | 验证整体数据误差选模，连续40轮未改善停止 |

## 5. 单卡怎样对应原四卡参照

新增两组各使用一张4090：reverse_shared在物理GPU 2，attention_time在物理GPU 3，均使用`ode`环境。

一个128人的优化批次仍按原四个rank的患者编号分成四份，每份最多32人。单卡依次处理四份，保留各份自己的补齐长度和输入dropout随机流。各字段的数据误差、校正前误差使用整批有效观测数作为分母，Jacobian使用整批有效状态数作为分母，ODE L2每个优化步骤计一次。

这样，共享参数得到的是同一个整批目标的累计梯度。CUDA检查会独立重算整批目标，核对损失和所有参数梯度；同时检查参数量、时间单位、未来信息隔离、注意力因果性和全部参数的有限梯度。

两组先通过检查及小规模完整训练测试，再正式训练。SwanLab、实际张量设备、物理GPU、固定源码SHA256和每轮恢复检查点随实验保存。参照检查点会在CUDA上重新测试，核对原有结果。

## 6. 怎样比较最终结果

主要比较前24小时历史之后的未来误差，同时报告历史重构、整体误差、未来6/12/24小时累计误差、原始单位MAE/RMSE、数值标准化MSE、GCS准确率和较短历史任务。

完成测试后逐组核对患者数、有效目标数和检查点重新载入结果。ADNI和MIMIC分别以各自的正向模型为参照，计算消融误差差值和相对误差降低，查看方向及编码方式的收益是否在两个数据集上保持一致。

在项目根目录启动：

```bash
bash scripts/run_mimic_history_encoder_ablation.sh
```

结果目录为`mimic_experiment/results/history_encoder_ablation_cuda/`。其中`summary.md`持续更新，`comparison.json`保存完整字段指标，`per_field_mae.csv`和`per_field_rmse.csv`提供逐字段比较。
