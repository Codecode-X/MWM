# MIMIC-IV 数据整理与 latent2x both 实验

模型结构、训练损失和测试流程的通用讲解，见[当前模型方法详解](../reproduction/CURRENT_MODEL_METHOD.zh-CN.md)。该文最后分别用ADNI和MIMIC真实病例展开说明。

HealthFlux-KL、ODE-AE、ODE-RNN、Latent ODE各单卡运行的新增比较，见[baseline实验方案](BASELINE_COMPARISON.zh-CN.md)与[实时横向比较](results/baselines_single_cuda/summary.md)。

## 1. 先把 ICU 记录变成可以学习的患者轨迹

本地 `/data/MIMIC/` 同时包含 MIMIC-III 1.4 和 MIMIC-IV 3.1。本次选用 **MIMIC-IV 3.1**：从患者入 ICU 后的连续检查记录中学习状态，再预测随后一天的变化。MIMIC-III 保留为单独的数据源。版本出处见 [PhysioNet 的 MIMIC-IV 3.1 页面](https://www.physionet.org/content/mimiciv/3.1/)。

一位患者只保留一次 ICU 住院。先找出该患者时间最早的 ICU 记录，再检查它是否符合入组条件。这样，每位患者在数据集中只有一条轨迹。

| 筛选步骤 | 剩余数量 |
|---|---:|
| 原始 ICU 住院记录 | 94,458 次 |
| 每位患者取首次 ICU 住院，年龄估计值至少18岁 | 65,366 人 |
| 首次 ICU 住院时长至少48小时 | 31,142 人 |
| 前24小时、后24小时各至少有6个非空观测窗口 | 31,072 人 |
| 前48小时完整落在住院期间，且死亡时间没有早于窗口终点 | **30,702 人** |

最后一步去除了370人。住院起止时间、ICU时间和死亡时间存在不一致时，不能仅凭 ICU 时长就认定存在完整的未来观察窗口。此次训练使用通过这项核查的数据，版本记为 `chronology_v2`。

这定义了一个明确的人群：**首次入住 ICU、住院和存活时间足以支持前48小时观察、前后两天都有观测的成年患者**。在这一人群上，我们评价连续生理指标预测。

患者按 `subject_id` 的固定 SHA256 哈希划分，训练、验证、测试比例约为70% / 15% / 15%。同一患者只属于其中一组。

| 数据划分 | 患者数 |
|---|---:|
| 训练 | 21,517 |
| 验证 | 4,649 |
| 测试 | 4,536 |

整理后共有 **1,181,642 个非空小时窗口**，每人最少14个、中位数39个、最多48个。年龄、性别、观测次数和字段覆盖图见[数据统计](results/dataset_profile/summary.zh-CN.md)。

## 2. 每个时间点记录什么

模型使用31个原始字段。其中27个为数值字段，3个为 GCS 分类字段，另有性别。类别展开后，解码器输出为44维。

| 类别 | 字段 | 单位或类别 |
|---|---|---|
| 生命体征 | 心率、收缩压、舒张压、平均动脉压 | bpm、mmHg |
| 呼吸与体温 | 呼吸频率、SpO₂、体温、FiO₂ | 次/分钟、%、℃、0–1比例 |
| 体重 | 体重 | kg |
| 血糖与肾功能 | 葡萄糖、尿素氮、肌酐 | mg/dL |
| 电解质 | 钠、钾、氯、碳酸氢根 | mEq/L |
| 其他化验 | 钙、镁、磷 | mg/dL |
| 血常规 | 白细胞、血红蛋白、红细胞压积、血小板 | K/μL、g/dL、%、K/μL |
| 乳酸 | 乳酸 | mmol/L |
| 血气 | pH、pCO₂、pO₂ | pH、mmHg、mmHg |
| 意识状态 | GCS睁眼、运动、语言反应 | 4类、6类、5类 |
| 静态资料 | 性别 | F / M |

生命体征及 GCS 来自 `chartevents`，化验来自 `labevents`。每个字段对应的 `itemid` 都已与本地字典逐项核对。生命体征的编码和范围参考 [MIT-LCP 的官方提取代码](https://raw.githubusercontent.com/MIT-LCP/mimic-code/main/mimic-iv/concepts/measurement/vitalsign.sql)。所有字段的单位和保留范围记录在 `schema.json`，来源编码与标签记录在 `verified_item_mapping.csv`。

体温统一转成摄氏度，FiO₂ 统一转成0–1比例。数值按公开写出的宽范围进行质量筛选；这些范围是清理规则。血气按原始血气项目提取，字段名称不额外指定动脉来源。

性别只在第一条真实观测中输入一次。此后保留缺失掩码，因此未来预测评价包含27个数值字段和3个 GCS 字段。住院死亡标记保存在患者元数据中，供人群统计使用；批次输入不读取它。出院诊断和出院信息也不进入模型。

## 3. 时间怎样处理

### 3.1 先确定信息何时可以被读取

检查记录包含测量时间 `charttime` 和记录入库时间 `storetime`。为避免把尚未入库的结果提前交给模型，本次使用两者较晚的时间作为可用时间；缺少入库时间时使用测量时间。两个时间字段的含义见 [MIMIC 的 labevents 文档](https://mimic.mit.edu/docs/iv/modules/hosp/labevents.html)。

例如，某次化验在入 ICU 后第5.2小时采样，第7.4小时入库，它会进入第7至8小时的窗口，在第8小时窗口结束时被读取。模型预测的对象也按这个时间规则整理，因此目标是**届时可获得的观测记录**。

`chartevents` 通过 `stay_id` 对应 ICU 住院。化验记录通过患者和时间窗口匹配；存在 `hadm_id` 时还要求住院编号一致。部分化验没有 `hadm_id`，此时根据同一患者和选定的 ICU 时间窗口匹配。这类缺失关联在 [MIMIC 的化验表说明](https://mimic.mit.edu/docs/iv/modules/hosp/labevents.html)中有说明。

### 3.2 再聚合为小时窗口

只保留入 ICU 后 `[0,48)` 小时内可获得的记录。每小时数值取均值；GCS 取众数，并列时取较小编码。窗口以结束时刻表示，因此时间为1至48小时。

某小时完全没有观测，就移除该行。某字段在保留的小时里没有观测，就保留缺失掩码；不进行前向填充或插值。比如第8小时后直接到第11小时，ODE 就按照3小时的间隔演化。

### 3.3 年龄与 ODE 时钟分别提供

ODE 的时间单位是**小时**。INIT 的年龄输入则由 `anchor_age + ICU年份 − anchor_year` 估计，换算到历史截止时刻后，以年为单位除以100。

MIMIC 的年龄采用去标识化锚点，超过89岁的 `anchor_age` 设为91，因此这里的年龄是锚点推算值。规则见 [patients 官方文档](https://mimic.mit.edu/docs/iv/modules/hosp/patients.html)。代码通过独立的 `initialization_age` 字段提供年龄，避免把 ICU 第24小时当作24岁。原 ADNI 路径继续使用原有输入方式。

### 3.4 最后只用训练患者拟合归一化

27个数值字段分别使用训练集有效观测的最小值、最大值做 min-max 归一化。验证和测试使用同一组参数，超出训练范围的值照常保留。缺失位置存为0，并通过掩码排除损失。

另存训练均值和标准差，供原始单位误差、标准差尺度误差和参考方法使用。

## 4. 模型如何训练和测试

沿用现有 **latent2x both** 的28维潜在状态、159宽 INIT / UPDATE / DECODER、188宽共享 ODE。编码时，患者状态按时间向前演化，遇到历史观测就执行 UPDATE。读取完历史后，从最后状态出发，向后积分重构历史，向前积分预测未来。未来阶段只运行 ODE 和解码器。

| 设置 | 本次取值 |
|---|---|
| 参数量 | **43,280** |
| INIT / UPDATE / DECODER / 共享ODE | 4,798 / 16,087 / 11,651 / 10,744 |
| 训练历史截止点 | 每人每轮从可用的6、12、18、24小时中选一个 |
| 主要验证和测试 | 前24小时观测 → 预测第24至48小时 |
| 补充测试 | 前6小时、前12小时 → 各自预测至第48小时 |
| 求解器 | 原有自适应 Tsit5，rtol=1e-4，atol=1e-6 |
| 输入观测 dropout | 0.1，仅训练使用 |
| 优化器 | Adam，学习率0.003，每2000步乘0.97 |
| 梯度裁剪 | 范数10 |
| 训练范围 | 最多300轮，最少50轮，验证整体误差连续40轮未改善则早停 |
| 选模与测试 | 取验证整体误差最小的检查点；重新载入核对后测试 |
| 随机种子 | 0 |
| 并行与批次 | 4张 RTX 4090，DDP，全局128，每卡通常32人 |

相比 ADNI 的44,875参数，参数量减少来自字段展开维度由49变成44，输入输出层随之适配。潜在维度和各网络宽度保持原设置。

损失保留 both 版本的五个部分：

\[
\mathcal L=\mathcal L_{\rm MSE}+\mathcal L_{\rm CE}
+0.02\mathcal L_{\rm ODE\text{-}L2}
+0.01\mathcal L_{\rm prior}
+0.01\mathcal L_{\rm jac}.
\]

1. **数值误差**：每个数值字段在有效观测上计算 MSE，再按字段求和。
2. **类别误差**：每个分类字段计算交叉熵，再按字段求和。
3. **ODE参数L2**：共享向量场的参数平方和，计一次。
4. **weak prior**：读取历史时，在 UPDATE 之前先解码，要求 ODE 演化到的状态能够解释新观测。首个观测和未来目标不参与此项。
5. **Jacobian正则**：在有效生成状态上计算完整28×28导数矩阵的784项平方和，再对状态取均值。采样位置停止梯度，向量场参数保留梯度。

Jacobian 沿用已验证的解析表达式，与对该两层 Tanh 向量场直接求导等价。

四卡分别处理患者，损失按全局字段观测数和全局有效状态数汇总，再补偿 DDP 的梯度平均。最后一批按实际人数归约，每轮患者不重复、不遗漏。启动流程先检查四卡与单卡同一批数据的损失和参数更新是否一致，再完成真实48小时数据的端到端预检查，通过后进入正式训练。

## 5. 如何阅读结果

[实时训练与最终结果](results/latent2x_both_cuda/summary.md)每30秒更新一次。正式测试会输出以下结果：

- 历史重构、未来预测、整体的字段 MSE＋交叉熵。
- 固定前24小时历史后，未来6、12、24小时累计误差。
- 27个数值字段在原始单位下的 MAE、RMSE，以及 GCS 分类准确率。
- 数值字段按训练标准差换算后的 MSE，逐字段等权平均。
- 与“保持最近观测值”的参考结果比较。某字段历史中从未出现时，参考方法使用训练均值或训练众数。
- 只有6小时或12小时历史时的预测结果及有效患者数。

测试批次只用历史掩码构造编码输入。已有 CUDA 检查通过修改全部未来值和未来掩码，验证模型预测及参考方法预测保持完全相同。

## 6. 文件保存在哪里

整理数据位于 `/data/MIMIC/derived/latentode_iv31/`。

| 文件 | 内容 |
|---|---|
| `dataset.pkl` | `schema`、患者 `sequences` 和 `metadata`，直接供训练读取 |
| `dataset_summary.json` | 人数、字段、归一化参数、时间规则和数据版本 |
| `cohort.csv` | 最终患者清单、划分及时间核查字段 |
| `schema.json` | 字段类型、单位、类别和质量范围 |
| `verified_item_mapping.csv` | 原始 itemid、来源表、字典标签 |
| `feature_profile.csv` | 字段观测覆盖和训练集分布 |
| `source/manifest.json` | 原始压缩表的来源、CRC32及SHA256 |
| `chartevents_audit.json`、`labevents_audit.json` | 流式扫描、筛选与单位统计 |

每条患者序列保存 `ages[T]`（ICU小时）、`values[T,31]`、`mask[T,31]`、患者和住院编号、数据划分、年龄估计值，以及供统计使用的元数据。`ages` 保留原接口名称，含义由数据集的 `time_unit` 明确指定。

正式输出位于 `mimic_experiment/results/latent2x_both_cuda/`。其中保存配置、四卡设备记录、逐轮历史、最佳检查点、SwanLab记录、最终指标、数据SHA256及实际执行的源码快照。

时间核查前的预检查轮次保存在 `latent2x_both_cuda_pilot_pre_chronology/`；对应旧缓存保存在数据目录的 `archive/pre_chronology/`。正式结果只使用 `chronology_v2`。

## 7. 复现入口

在仓库根目录运行：

```bash
# 使用现有 ode 环境；整理数据、四卡检查、正式训练和最终测试连续执行。
bash scripts/run_mimic_latent2x_both.sh

# 只整理数据，CPU执行表格扫描和聚合。
/home/xjh/miniforge3/envs/ode/bin/python -m mimic_experiment.prepare

# 汇总已整理数据并绘图，CPU执行统计。
/home/xjh/miniforge3/envs/ode/bin/python -m mimic_experiment.profile
```

入口检测到任务正在运行时会退出，已有输出会保留。新建独立实验可通过 `--output` 指定新目录。模型训练、验证、检查点测试及Jacobian计算均在物理GPU 0、1、2、3上执行；设备不可用时程序报错。
