# ODE-AE 原文与实现的逐项对照

这份文档按模型、学习目标、数据和评估的顺序说明实现。每一部分先介绍论文给出的内容，再记录当前代码采用的设置。

论文出处、PDF 校验值和求解器系数来源见 [provenance.json](../reference/provenance.json)。本次阅读了论文 Methods 的模型架构、Algorithm 1、训练公式、评价方式以及 Tables 2–3。查阅过程中尚未找到可以核对这些细节的作者实现，因此代码属于基于论文重建的 PyTorch 版本。

## 1. 反向编码与首次检查处的初始状态

论文先用患者最后一次历史检查的年龄初始化编码状态。随后从后向前逐次处理历史：先用 ODE 退回上一个检查时间，再用检查值更新编码状态。

代码中的 `PaperModel` 采用这一顺序。初始化网络接收年龄，更新网络接收当前状态与检查输入，反向 ODE 独立保存参数。缺失字段在输入位置置零。

ODE-AE 的编码状态为 12 维，最后拆为 6 维均值和 6 维对数方差。生成过程从首次检查处开始，沿正向时间恢复整个序列。确定性版本使用 6 维编码状态，直接作为生成初值。

这种首次检查锚点与此前 `src/adni_models.py` 中面向未来任务的截止点锚定不同，所以本目录单独实现模型。

## 2. 生成 ODE 与数值求解

论文选定的生成潜在维度为 6，生成 ODE 有一个 16 神经元隐藏层，采用 Tsitouras 5/4 自适应积分。

本目录使用相同阶数与系数的自适应求解器，直接在 CUDA 上执行 PyTorch 运算。系数取自 Diffrax v0.7.0，保存于 [tsit5_tableau.json](../reference/tsit5_tableau.json)，许可见 [Diffrax.LICENSE](../reference/Diffrax.LICENSE)。前向与反向时间都通过真实的年龄间隔积分。

这里每段积分计算末端状态，误差控制使用本目录实现的比例调节。论文使用 JAX/Diffrax，其步长控制和插值实现不同。当前误差容限固定为 `rtol=1e-4`、`atol=1e-6`；原文没有给出这两个值。

## 3. 更新网络和 LSTM 怎样选取

原文说明了初始化、更新和解码网络的用途，但没有完整列出各网络的层宽、激活函数和全部连接细节。当前代码把这些设置作为显式实现选择：

| 部分 | 当前设置 |
|---|---|
| INIT、UPDATE、DECODER | 一个 16 神经元隐藏层，Tanh 激活 |
| 反向编码 ODE | 一个 16 神经元隐藏层，Tanh 激活 |
| 年龄初始化输入 | 年龄除以 100；ODE 间隔仍以年计 |
| 方差稳定处理 | 对数方差限制在 −12 到 8 |
| 梯度裁剪 | 上限 10 |

论文对 LSTM 的描述是用 LSTM 替换 ODE 编码和生成部分。当前基线采用反向 LSTM 编码器和正向 LSTM 生成器，向递归单元提供年龄信息，保留高斯初始状态。具体 LSTM 连接与状态大小仍需要作者实现来核对。

这些选择允许三个模型在同一接口下训练，也使后续核对作者代码时能够明确定位需要调整的部分。

## 4. 学习目标怎样对应训练公式

论文先对每个数值字段在有效观测上的平方误差求平均，再把各字段相加。类别字段采用相同的字段级计数方式，计算类别交叉熵。

`feature_errors` 为每个原始字段计算误差，`reconstruction` 完成字段内平均与字段间求和。因此，独热编码的一个类别字段不会被错误地算作多个独立目标。

ODE-AE 的总学习目标包括四部分：

```text
数值字段 MSE 之和
+ 类别字段交叉熵之和
+ KL 权重 × 初始状态分布的 KL
+ L2 权重 × ODE 参数的正则项
```

KL 使用高斯分布到标准正态分布的解析式，先对潜在维度求和，再对样本平均，不除以潜在维度。与 Table 2 选定设置一致，KL 权重为 1，L2 权重为 0.02。

当前 L2 采用正向与反向 ODE 参数的平方和。数值和类别项的权重均设为 1。确定性模型的 KL 为零；LSTM 基线没有 ODE 参数，所以当前不对它施加这个 ODE 专用正则项。是否需要为 LSTM 增加对应正则，要结合作者基线设置继续核对。

训练使用所有可能的历史截断，包括完整历史作为输入的情况。每条截断样本都以完整序列作为目标，因而同时学习历史重构与未来预测。输入随机遮挡比例设为 10%，这是原文未指定的实现参数。

## 5. 数据与 46 字段合同

字段清单根据论文 Table 1 和字段说明整理为 46 项。性别、婚姻状态、利手和诊断被设为类别字段，其余字段采用数值形式。原文没有完整给出类别编码规范，当前分类方式保存在 JSON 合同中，可以追溯和调整。

本地适配器优先按患者、阶段和访视代码合并原始表。对于没有阶段信息的表，保留日期来区分同名访视，避免不同年份的同名代码被合并。访视日期按 EXAMDATE、VISDATE、SCANDATE 的优先顺序选取，再按自然年季度聚合。

同季度数值取均值，类别取多数。时间戳放在季度右边界。人口学使用首次可用记录；APOE 转为 ε4 等位基因数量。生日只有年份时采用该年 7 月 1 日，只有月份时采用该月 1 日。

左右海马体积先求和，再计算相对首次可用测量的百分比变化。PET 使用通过完全视觉质控的记录，对可用皮质区域按体积加权计算 SUVR。

当前 CSF 使用本地 Roche 表代替论文涉及的 UPENN MASTER 来源。皮质体积变化与其余五项缺少字段列入数据审计。完整字段模式会在存在缺失项时停止准备。

归一化默认使用训练集 min-max，也支持显式切换为训练集 z-score。论文只说明已经归一化，没有给出足以确认具体变换的信息，所以这里保留为需要进一步核对的条件。

## 6. 训练和评价安排

Table 2 给出初始学习率 0.003、衰减比例 0.97、衰减步数 2,000。代码使用连续的指数衰减，每次优化更新后推进一次调度器。

批量大小 32、最大 300 轮、最少 50 轮以及 40 轮早停耐心值，是当前运行配置。它们用于先建立可执行的正式训练入口。

每轮按验证集整体重构误差选择检查点。训练结束后重新加载最优检查点，分别计算验证和测试的插值、预测及整体误差。

点预测使用论文采用的 ME 方式，即把后验均值作为初始潜在状态。评价时不把 KL 和 L2 加到重构误差中。包含全部历史的截断样本参与插值和整体评价，但没有未来目标；它不会增加预测误差的观测计数。

论文没有给出可恢复到原患者列表的划分文件，也没有明确所有评价截断的抽取细节。当前本地评价使用全部截断，划分沿用数据集已有患者分组。

## 7. 已经完成了哪些核对

CUDA 检查覆盖六项内容：全部历史截断的枚举、Tsit5 正反向精度与梯度、未来值隔离、首次检查锚点与填充处理、字段级误差求和，以及三个模型的有限梯度。

四个小规模任务分别在四张 GPU 上运行。每个任务训练一轮，完成验证选模、保存、重载与测试。设备和核对结果见各任务的 `hardware.json`、`metrics.json`，汇总状态见 [validation_status.json](../reference/validation_status.json)。

这些检查把数据和模型链路连通。接下来可以先完成本地 40 字段的正式比较，再随着字段、划分与作者实现细节的补齐，推进论文效果的复现。
