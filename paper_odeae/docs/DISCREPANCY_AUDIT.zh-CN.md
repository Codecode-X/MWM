# 为什么本地复现实验与论文结果不同

## 1. 先确定本次核查的对象

本次核查使用已经完成的五个正式任务：ODE-AE seed 0、1，Deterministic seed 0，以及 LSTM seed 0、1。原训练结果和检查点保留原样，没有为了接近论文数字修改模型或重新选取测试检查点。

核查分为三部分：阅读论文与实现、统计已有数据和指标、在 CUDA 上检查已完成模型。模型检查分别使用物理 GPU 0、1、2、3，设备记录保存在 [诊断结果目录](../results/discrepancy_audit/)。

论文依据为 [原文 Methods、Table 1–3](https://www.mate.polimi.it/biblioteca/add/qmox/49-2025.pdf)。本地保存的论文 PDF SHA256 与来源记录见 [provenance.json](../reference/provenance.json)。当前代码是独立的 PyTorch 重建，尚没有可核对的作者实现。

## 2. 两边的绝对误差为什么不能直接相等

### 2.1 数据范围和参与平均的记录不同

| 条件 | 论文 | 当前数据 |
|---|---|---|
| 字段数 | 46 | 40 |
| 训练 / 验证 / 测试患者数 | 2451 / 613 / 766 | 2093 / 393 / 414 |
| 患者总数 | 3830 | 2900 |
| 季度聚合后的记录数 | 15851 | 17165 |
| 患者划分 | 作者划分 | 本地已有划分 |

本地缺少 ECog 自评、ECog 同伴评估、NPI、顶叶 FDG、颞叶 FDG 和皮质体积变化。原文和本地都将各字段误差相加，所以少六个字段本身就改变了总误差。各字段难度和尺度不同，不能乘以 46/40 来校正。

本地患者更少，但季度记录更多，说明实际纳入的患者、访视或聚合结果存在差异。当前处理还要求患者至少有两个有效季度，并沿用本地划分。仅凭论文汇总数，尚不能定位是哪一项筛选或合并规则造成记录数差异，需要作者患者及访视清单才能逐条核对。

本地 CSF 使用 Roche 来源代替论文部分 UPENN MASTER 来源。检测平台、缺失比例及量程也可能不同。这些是数据条件差异，不能靠增加随机种子消除。

### 2.2 归一化直接改变误差的单位

论文说明进行了归一化，但未给出足够细节来恢复具体变换。当前实现明确采用训练集 min-max。因而不能认定本地与论文使用了相同数值单位。

做一个固定预测的单位换算即可看到影响：ODE-AE seed 0 的测试数值 MSE 之和为 **0.8995**；将同一组预测误差换算为训练集标准差单位后，变为 **29.0507**。这里没有重新训练，也没有改变预测，只更换了数值单位。这个计算不能说明作者使用了 z-score，它说明绝对误差对归一化高度敏感。

归一化还影响训练。当前 KL 权重为 1，但数值重构项在 min-max 下较小。即使抄用了论文的 KL 权重，只要重构项尺度不同，KL 与重构之间的相对作用也不同。因此，“超参数数值相同”还不能保证“优化目标的平衡相同”。

单位换算与数据计数见 [statistical_reference.json](../results/discrepancy_audit/statistical_reference.json)。

## 3. 再检查本地模型之间为什么差距过大

### 3.1 大部分差距来自类别字段

先比较共同的 seed 0，避免混入不同数量种子的平均值：

| 模型 | 测试数值 MSE 之和 | 测试类别交叉熵之和 | 测试整体误差 |
|---|---:|---:|---:|
| ODE-AE | 0.8995 | 2.2156 | 3.1151 |
| Deterministic | 0.5910 | 0.3388 | 0.9298 |
| LSTM | 0.8785 | 2.8424 | 3.7209 |

ODE-AE 与 Deterministic 整体相差 2.1853，其中类别交叉熵相差 1.8768，约占 **86%**。主要字段如下：

| 类别字段 | ODE-AE | Deterministic |
|---|---:|---:|
| 诊断 | 0.9868 | 0.3351 |
| 婚姻状态 | 0.5514 | 0.0019 |
| 利手 | 0.3787 | 0.0008 |
| 性别 | 0.2988 | 0.0011 |

后三项人口学信息在本地按患者复制到每次访视，因而历史中已有直接线索。确定性版本能保留这些信息，概率版本却有明显损失。仅用“本地少六个字段”不能解释这种模型间差距，需要继续检查潜在表示。

### 3.2 LSTM 几乎没有利用患者历史

使用训练集均值和类别频率构造一个不读取患者历史的统计参照，按当前相同的全部截断和字段计数方式计算，其测试整体误差为 **3.7674**。LSTM 两个种子的结果为 **3.7209、3.7174**，只比这个参照低约 1.2%–1.3%。

随后在固定的 64 位验证患者上检查 LSTM seed 0，共包含 331 个历史截断：

| 检查项 | 结果 |
|---|---:|
| 有历史输入时的整体误差 | 3.7692 |
| 历史输入全部遮挡后的整体误差 | 3.7703 |
| 后验均值的均方根 | 0.01224 |
| 后验标准差均值 | 0.99988 |
| 每个截断样本的平均 KL | 0.000456 |

均值接近 0、标准差接近 1，且去掉历史几乎不影响预测，这些结果共同支持“后验塌缩”的判断：潜在分布接近标准正态，模型主要学习总体分布，而没有充分编码患者差异。全部遮挡属于干预诊断，不能当作真实部署数据的效果估计。

代码中还有一个具体的结构限制：[models.py](../models.py) 直接把 LSTM 最后的隐藏状态拆成 `mu` 和 `logvar`，没有独立投影层。标准 LSTM 的隐藏输出位于 −1 到 1 之间，因此这里的 `logvar` 也被限制在该范围，后验标准差无法低于 `exp(-0.5) ≈ 0.6065`。模型不能通过这个分支输出更窄的分布。

这个限制是本地 LSTM 构造带来的；原文只简述用 LSTM 替换相关模块，没有提供足以确认该构造的细节。因此，当前 LSTM 基线需要重新核查，而不能直接视为作者基线的等价实现。隐藏状态限制与 KL 共同作用是塌缩的合理机制，但各因素的因果贡献仍需控制变量实验验证。

### 3.3 ODE-AE 存在明显的信息瓶颈，但没有完全忽略历史

在同一个验证子集上，两个 ODE-AE 种子的平均 KL 分别为 **0.3770、0.4217**，后验标准差均值分别为 **0.9603、0.9511**。潜在均值变化中，最大主成分分别占总方差的 **99.58%、98.78%**，说明六维表示的变化高度集中在单一方向。协方差特征值也保存在诊断 JSON 中。

ODE-AE seed 0 遮挡历史后，误差从 **3.0488** 上升到 **3.8559**。所以它确实利用了历史，只是保存的信息比确定性版本少。不能把它与 LSTM 一起笼统称为完全塌缩。

另外，两个 ODE-AE 种子的完整测试整体误差分别为 **3.1151、3.1159**，虽然最佳轮次分别为 50 和 128，结果仍十分接近。这降低了“只是 seed 0 偶然训练不好”这一解释的可信度。训练目标的尺度、KL 约束、网络表达及优化设置更值得优先检查。

这些观测还不能证明论文的 KL 权重应该改成某个值。后续的 KL 消融应当用于查明机制，不能为了接近论文表格而直接调节权重。

## 4. 哪些常见问题本次没有得到支持

### 4.1 不是把 KL 或 L2 错加进了测试误差

当前评价函数只累计字段重构误差；KL 和 L2 仅用于训练。四个字段的类别交叉熵按原始字段计数，没有把独热编码展开后的每个类别重复算成独立字段。此处与原文基本定义一致。

### 4.2 暂未发现未来值被直接读入编码器

CUDA 检查将未来观测改成其他值，预测保持不变；也核对了首次检查锚点和填充位置。六项检查全部通过。它们说明这些已覆盖的代码路径符合预期，尚不等于完成了原始数据各字段时间来源的全面审计。

### 4.3 当前 ODE 容差不是主要解释

在相同参数和验证子集上，将 `rtol`、`atol` 都缩小到原来的十分之一，两个 ODE-AE 的整体误差变化为 0，Deterministic 变化约 **2.0e-9**。已保存结果的检查点重载核对也为 0。

因此，当前积分容差或保存重载误差不能解释数量级差距。这个检查仅针对已训练参数的前向结果，不证明自实现求解器与 Diffrax 的训练轨迹完全相同。

## 5. 下一步按什么顺序处理

| 顺序 | 工作 | 需要回答的问题 |
|---|---|---|
| 1 | 明确归一化、类别编码和字段合同；继续追溯原始来源 | 两边到底在用什么单位、什么目标比较？ |
| 2 | 核查并修订 LSTM 分布参数输出方式，单独保存新版本 | 去除有界输出限制后，是否仍然忽略患者历史？ |
| 3 | 用固定划分和 seed 0 做受控的 KL / 重构尺度消融 | 概率模型的信息瓶颈主要由哪一项造成？ |
| 4 | 核对患者、季度访视、截断权重与作者网络细节 | 剩余差距是否来自队列与实现设置？ |
| 5 | 方法和评估条件确认后，再增加种子 | 剩余差异中有多少属于随机波动？ |

到这里可以把问题分为两层：绝对误差无法与原文直接对齐，已知存在字段、数据和尺度差异；模型间差距过大，则已有 LSTM 后验塌缩和 ODE-AE 信息瓶颈的实际证据。尚未完成控制变量实验的原因保留为待验证机制。

## 6. 如何复查证据

以下命令只生成独立诊断结果，不覆盖正式实验。第一条执行四卡模型诊断，第二条统计缓存和保存的指标，第三条在 CUDA 上运行模型检查：

```bash
conda activate ode
python -m paper_odeae.diagnostics.audit_checkpoints
python -m paper_odeae.diagnostics.statistical_reference
CUDA_VISIBLE_DEVICES=0 python -m unittest paper_odeae.tests.test_models -v
```

每个诊断任务包含 64 位验证患者的全部截断。该子集结果用于机制分析；与论文并列的正式测试指标仍取原始完整测试结果。单次随机采样重构误差只作为辅助记录，不能替代论文中的多次采样 MC 均值评价。
