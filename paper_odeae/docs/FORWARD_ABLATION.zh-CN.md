# 正向吸收历史、截止点锚定的确定性 ODE-AE 消融

## 1. 从患者状态估计的过程定义实验

设患者已有第 1、2、3 次检查，需要预测第 4 次。新增模型先确定一个初始编码状态，再按第 1、2、3 次的顺序吸收观测：两次检查之间用编码 ODE 演化，到达检查时用原有 MLP 更新状态。

最后一次历史观测更新后的状态表示第 3 次检查时的患者状态。未来预测从这个截止点状态向前积分；历史重建则从同一个状态向过去积分。两条生成过程使用同一个生成 ODE，但分别从截止点状态重新出发，避免先重建过去、再折返未来带来数值往返误差。

这与 ODE-RNN 一样按时间正向吸收历史，但保留了确定性 ODE-AE 的 MLP 观测更新、独立编码/生成 ODE，以及不反馈预测的生成方式。它没有改成 GRU，也没有增加未来自回归更新。

## 2. 两种初始化都保留

| 版本 | 编码开始前的状态 | 历史顺序 | 生成锚点 | 可训练参数量 |
|---|---|---|---|---:|
| 当前扩容原版 | INIT 网络读取历史截止点年龄 | 反向 | 首次检查 | 22545 |
| 新增 forward_age | 相同 INIT 网络读取相同截止点年龄 | 正向 | 历史截止点 | 22545 |
| 新增 forward_zero | 全零状态，不使用年龄 INIT | 正向 | 历史截止点 | 21307 |

年龄初始化版保留原代码的输入定义，即 `INIT(历史截止点年龄 / 100)`；它不是用未来的年龄或检查结果。零初始化版在第一次观测进入前不含患者特异信息，随后从历史检查及其间隔估计状态。年龄仍可能作为已有历史检查字段被读取。

两组的共享网络使用相同初始化权重；零初始化版移除 INIT 时，不改变其他网络初始化的随机数顺序。这里“逐步估计状态”是结构设计，不代表每吸收一次观测，实际估计误差都必然单调下降。

## 3. 保持哪些设置一致

两个新增模型沿用当前 22,545 参数原版的潜在维度 6、MLP 隐藏层宽度 154、前后向 ODE 隐藏层宽度 118，不通过调整宽度补齐零初始化版的参数数。INIT 网络原本有 1,238 个参数，所以删除后实际为 21,307。

数据缓存、患者划分、归一化、全部历史截断、遮挡概率、损失、ODE 求解器及容差、全局 batch 32、学习率和更新步调度、seed 0、选模规则、最多 300 轮/至少 50 轮/耐心值 40 均保持一致。

两组都使用四卡 DDP，每卡 batch 8。队列还会核对控制组的数据 SHA256、关键训练设置与四卡布局。未来测试列只在完整任务结束并重载检查点后填入。

## 4. 怎样解释比较

forward_age 与 forward_zero 相互比较，用于检查年龄初始化相对零初始化的影响。两组共享网络相同，但年龄版多一个实际参与学习的 INIT，因此它们不是严格等参数对照。

原反向版与 forward_age 参数数量相同，区别包括读取方向和生成状态锚点。它回答“改成正向状态估计、截止点推断后效果怎样”，不能把全部变化单独归因于读取方向。历史重建仍可利用截止点前的全部观测，因而也不能与 ODE-RNN 先预测后读取当前观测的历史评分完全等同。

## 5. 运行安排与结果位置

当前反向原版占用四张 GPU，队列等待它成功结束并释放 GPU 后，依次执行 forward_age、forward_zero。每个正式任务前先进行四卡单步一致性和端到端小规模检查。不会打断当前实验，也不会同时向同一 GPU 塞入多个正式训练任务。

```bash
conda activate ode
python -m paper_odeae.run_direction_ablation
```

- [零初始化](../configs/deterministic_forward_from22545.json)
