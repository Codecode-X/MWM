# 确定性 ODE-AE 的表现、结构差异与参数量对照

## 1. 先比较参数量接近的已有结果

目前最接近的一组是 2,505 参数的确定性 ODE-AE 与 2,719 参数的 ODE-RNN。它们都使用同一份 40 字段数据、同一患者划分、全部历史截断和 seed 0。

| 模型 | 可训练参数量 | 测试插值 | 测试预测 | 测试整体 |
|---|---:|---:|---:|---:|
| 确定性 ODE-AE | 2505 | 0.7167 | 1.2061 | 0.9298 |
| ODE-RNN，小容量 | 2719 | 1.5470 | 1.2543 | 1.4198 |
| ODE-RNN，原容量 | 22545 | 1.3708 | 1.1206 | 1.2641 |

在参数量接近的小模型组中，确定性 ODE-AE 的整体误差更低，未来预测误差也略低。两者不是严格相同参数量，且只有一个种子，所以这还不是“同参数量下必然最优”的结论。原容量 ODE-RNN 的未来预测误差则优于当前确定性 ODE-AE。

## 2. 两种模型怎样使用历史

### 确定性 ODE-AE：先概括整段历史，再生成轨迹

模型从历史截止点开始，按时间反向读取已知检查。在两次检查之间用反向 ODE 演化状态，在检查处用 MLP 融合观测。处理完成后，得到首次检查处的一个确定性潜在状态。

生成过程从首次检查开始，用另一个正向 ODE 连续演化，并通过解码器输出所有检查时间点的预测。它可以利用截止点之前较晚的观测，帮助重构较早的历史；到了未来阶段，则只沿生成 ODE 推进，不再读取真实值。

### ODE-RNN：沿时间逐次预测和更新

模型从零状态出发，按时间正向处理。先用 ODE 推进到当前检查时间并输出预测，然后再把当前已知检查交给掩码 GRU 更新状态。

进入未来后，它仍在每个查询时间点进行递归更新，只是输入改为自身预测。预测误差因此可能通过反馈影响后续状态。当前适配器对类别反馈使用预测概率，对数值反馈使用预测数值。

| 结构方面 | 确定性 ODE-AE | ODE-RNN |
|---|---|---|
| 历史方向 | 从后向前 | 从前向后 |
| 初始条件 | 截止点年龄初始化编码，最终得到首次检查潜在状态 | 零状态初始化 |
| 观测更新 | MLP | 带缺失掩码的 GRU |
| 动力学网络 | 编码和生成各一个 | 一个 |
| 未来阶段 | 生成 ODE 连续推进 | ODE 推进并反馈预测进行递归更新 |
| 历史评分时的信息 | 可用截止点之前全部历史 | 当前时刻预测先于读取当前观测 |
| KL 与采样 | 无 | 无 |

这里比较的两者都没有 KL 和采样，因此不能用“去掉 KL”解释它们之间的差距。KL 是确定性版本相对概率 ODE-AE 的另一项差别。

## 3. 哪些因素有证据支持，哪些还只是机制解释

### 3.1 整体优势有很大一部分来自历史类别字段

确定性 ODE-AE 的历史类别交叉熵为 **0.1823**，小 ODE-RNN 为 **0.9057**；两者的历史数值 MSE 分别为 **0.5344、0.6413**。历史类别项的差距明显更大。

性别、婚姻状态、利手等字段在本地数据中按患者复制到各次访视。确定性 ODE-AE 在重构第一次检查时，已经可以利用截止点前的其他检查；因果 ODE-RNN 第一次预测发生在读取任何检查之前，缺少同等信息。因此，历史和整体指标天然更有利于平滑重构模型，不能全部归因于参数效率。

### 3.2 在共同的未来目标上，差距明显缩小

确定性 ODE-AE 的未来误差为 **1.2061**，小 ODE-RNN 为 **1.2543**。拆分如下：

| 模型 | 未来数值 MSE 之和 | 未来类别交叉熵之和 |
|---|---:|---:|
| 确定性 ODE-AE | 0.6689 | 0.5372 |
| 小 ODE-RNN | 0.7196 | 0.5347 |
| 原容量 ODE-RNN | 0.5695 | 0.5511 |

小模型之间的未来优势主要来自数值预测，类别预测已经接近。原容量 ODE-RNN 的数值误差进一步下降，最终获得更低的未来总误差。

### 3.3 编码、初始化和未来生成方式可能影响小模型效率

反向编码把整段历史集中到一个适合生成完整轨迹的初始状态，年龄初始化也提供了直接时间信息。生成阶段没有预测反馈更新，可能减少一类误差累积。小 ODE-RNN 则需要用一个较小状态同时完成观测融合与自回归预测。

这些是根据结构提出的合理解释，尚未用单独消融确定各自贡献。参数总数相同，也不代表模块分配相同。此外，当前 ODE-AE 使用年的时间单位，ODE-RNN 适配器沿用十年单位，这使同系数的 ODE 参数 L2 正则也不完全等价。不能把全部差距解释为某一个结构优点。

## 4. 怎样精确扩大到 22,545 个参数

本次扩容对象为当前讨论的**确定性 ODE-AE**。保持潜在维度 6，只扩大隐藏层，不添加闲置参数。40 个原始字段展开后的输入宽度为 49。

设潜在维度为 d，INIT/UPDATE/DECODER 共用隐藏层宽度为 m，两个 ODE 的隐藏层宽度为 o，则可训练参数数为：

```text
P = m × (4d + 2×49 + 4) + o × (4d + 2) + 4d + 49
```

取 `d=6, m=154, o=118`，得到：

```text
P = 154×126 + 118×26 + 73 = 22,545
```

该计数与原容量 ODE-RNN 的可训练参数数严格相等。原容量 ODE-RNN 还有冻结且未使用的分类头，不计入匹配目标。配置见 [deterministic_22545.json](../configs/deterministic_22545.json)。

## 5. 四张 GPU 如何共同训练

本次用 DDP 训练同一个 seed 0 模型，物理 GPU 0、1、2、3 各一个进程。保持**全局 batch size 32，每卡 8**，不把全局 batch 扩成 128。完整训练集每轮仍有 392 次优化更新，学习率调度的更新步数保持一致。

由于各字段的缺失比例不同，四卡不能直接平均各卡独立计算的字段平均误差。实现先汇总全局字段观测数，再对每卡误差分子使用这个分母，反向时补偿 DDP 的梯度平均。验证和测试按截断样本无重复分片，最终汇总字段误差分子和观测数。

学习率、衰减、输入遮挡概率、ODE 容差、L2 系数、选模规则和 300/50/40 训练预算均保持原值。各卡使用可复现的独立数据增强随机流；自适应积分的批次构成也改变，因此不能声称分卡后的完整优化轨迹与单卡逐位相同。

启动命令：

```bash
conda activate ode
python -m paper_odeae.run_capacity
```

正式记录位于 `paper_odeae/results/capacity_matched/deterministic_22545/seed_0/`，SwanLab 中为一个全局训练实验。每卡物理编号与实际张量设备分别写入设备记录。已有完成或未完成历史的目录会受到保护，不自动覆盖。

## 6. 已经完成的四卡检查

四卡与单卡在同一个全局 batch 上计算的损失一致；一次 SGD 更新后，参数最大差异约 **1.5e-8**。小规模端到端检查完成训练、分布式验证选模、保存、重载和测试。

同一个小规模检查点另用原单卡评价函数计算，两者验证和测试误差最大差异小于 **1.4e-7**，各字段观测数量相同。检查结果保存在 `paper_odeae/results/capacity_checks/`。

正式实验结束后，将使用与原 ODE-RNN 相同的未来预测目标比较 22,545 参数模型。大表会自动加入新行，在任务结束前只展示验证进度，不填造测试结果。
