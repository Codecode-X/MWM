# ADNI：历史读取方向与ODE编码作用的等参数消融

相同设计已继续接入MIMIC，见[MIMIC实验说明](../mimic_experiment/HISTORY_ENCODER_ABLATION.zh-CN.md)与[跨数据集比较](../mimic_experiment/results/history_encoder_ablation_cuda/summary.md)。

## 1. 从现有模型提出两个问题

latent2x both先按时间读取患者历史。相邻检查之间，状态沿ODE演化；遇到观测，UPDATE校正状态。读取结束后，从最后一次历史检查处的状态出发，向过去重构、向未来预测。

这轮实验分别研究：

1. 如果沿同一个速度场，从后往前读取历史，再从首次检查处向前生成，效果怎样？
2. 如果直接用注意力和实际时间编码形成历史状态，再保留ODE生成轨迹，效果怎样？

参照使用已经训练完成的[latent2x both](results/latent2x_loss_ablation/both/seed_0/metrics.json)。新增两组从seed 0独立初始化训练，[实时比较文档](results/latent2x_history_encoder_ablation/summary.md)持续汇总进度与结果。

## 2. 共同的数据与任务

继续使用同一份ADNI缓存`paper_odeae/cache/local_available.pkl`，对应最初整理的本地ADNI纵向病例。数据SHA256与参照实验记录核对。

| 内容 | 三组共同设置 |
|---|---|
| 训练 / 验证 / 测试患者 | 2,093 / 393 / 414 |
| 字段 | 40个有训练观测的字段，展开为49维输出 |
| 归一化 | 训练集min-max，验证和测试复用 |
| 时间 | 实际年龄差，单位为年 |
| 历史截止点 | 枚举每位患者的全部非空历史前缀 |
| 监督目标 | 有真实观测的历史和未来字段 |
| 检查点选择 | 验证整体数据误差最小 |

例如，一位患者有六次检查，就分别构造已知前一次、前两次，直到前六次的任务。每个任务只把对应历史前缀交给编码器；其余观测作为未来标签。三组使用完全相同的患者划分、前缀和目标掩码。

## 3. 三组怎样处理同一段历史

设患者在63岁、64.25岁、66岁有三次已知检查，需要预测67.5岁的情况。

### 3.1 参照：正向ODE编码

```text
年龄INIT
  → 读取63岁观测
  → ODE推进1.25年 → 读取64.25岁观测
  → ODE推进1.75年 → 读取66岁观测
  → 得到66岁状态
```

主生成从66岁状态出发。向过去积分重构已知检查，向未来积分预测67.5岁。历史编码与生成使用同一套速度场。

### 3.2 reverse_shared：反向读取，仍共享速度场

```text
相同年龄INIT
  → 读取66岁观测
  → 同一ODE反向推进1.75年 → 读取64.25岁观测
  → 同一ODE反向推进1.25年 → 读取63岁观测
  → 得到63岁状态
```

这个63岁状态已经吸收三次已知检查。主生成直接从它出发，沿共享ODE向前生成，经过64.25岁、66岁，再到67.5岁。生成途中继续自由积分。

这里保留原INIT、UPDATE、DECODER、速度场的全部结构和参数。主编码方向改变，生成起点对应放在反向编码的终点。两次检查之间的反向积分使用负时间差，仍调用同一个速度网络。

### 3.3 attention_time：用注意力直接形成截止状态

三次观测分别变成28维token，加上真实经过年数的正余弦时间编码，以及同一个年龄INIT提供的信息。以首次检查为时间零点，这里的时间位置为0、1.25、3年。

一层四头因果自注意力处理这些token。第一个状态读取第一次观测，第二个状态读取前两次观测，第三个状态读取全部三次观测。取第三个状态作为66岁的估计。

之后的主生成与参照相同：从66岁状态向过去重构、向未来预测，使用原来的共享ODE和解码器。历史注意力编码本身直接处理观测与时间，不调用ODE积分。

时间编码由实际年数计算，周期固定在0.25至20年之间，共14组正余弦。它没有可学习参数。因果掩码和患者自身的历史截止掩码共同限制可读记录。

## 4. 怎样保持相同参数量

三组均为28维状态、**44,875个可训练参数**。

| 模块 | 正向参照 | reverse_shared | attention_time |
|---|---:|---:|---:|
| INIT：1 → 159 → 28 | 4,798 | 4,798 | 4,798 |
| 共享ODE：28 → 188 → 28 | 10,744 | 10,744 | 10,744 |
| DECODER：28 → 159 → 49 | 12,451 | 12,451 | 12,451 |
| 历史观测编码 | UPDATE，16,882 | 相同UPDATE，16,882 | 时间注意力，16,882 |
| 总计 | **44,875** | **44,875** | **44,875** |

注意力模块的预算具体分配如下：

| 组成 | 结构 | 参数量 |
|---|---|---:|
| 观测嵌入 | 49 → 59 → 28，末层无偏置 | 4,602 |
| 四头自注意力 | 状态维度28，每头7维 | 3,248 |
| 前馈网络 | 28 → 156 → 28 | 8,920 |
| 两个LayerNorm | 各28维 | 112 |
| 实际时间正余弦编码 | 固定函数 | 0 |
| 合计 | 替换原UPDATE的预算 | **16,882** |

模型先按原顺序构建共有网络，再替换注意力组的编码模块。因此，相同seed下，保留模块的初始权重逐项相同。CUDA检查同时确认所有可训练参数都获得有限梯度。

## 5. 怎样保留both的训练损失

三组使用：

\[
L=L_{\mathrm{data}}+0.01L_{\mathrm{prior}}+0.01L_{\mathrm{jac}}+0.02L_{\mathrm{ODE\text{-}L2}}.
\]

数据项为有效数值字段的MSE与类别字段的交叉熵。各字段先按有效观测取平均，再求和。Jacobian项保持完整28×28导数矩阵的平方范数，对有效生成状态取平均，采样位置停止梯度。共享ODE的参数L2只计一次。

weak prior继续回答同一个问题：只知道此前观测时，能否预测下一次检查？从第二条历史记录开始计算。

| 模型 | 怎样得到下一次检查前的预测 |
|---|---|
| 正向参照 | 上一次UPDATE后的状态，沿共享ODE推进到下一次检查 |
| reverse_shared | 用同一套网络做辅助正向扫描，按原参照定义得到预测 |
| attention_time | 取截至上一次检查的因果注意力状态，沿共享ODE推进到下一次检查 |

反向组的辅助正向扫描只提供weak prior监督，其状态不进入反向主编码的结果，也不作为主生成起点。它没有增加网络或参数。这样，反向组保留原有的因果预测损失，主重构和未来预测由反向编码结果决定。

注意力组的ODE用于主生成和weak prior预测；注意力历史状态由观测、时间、年龄信息直接形成。CUDA检查会临时禁止ODE调用，验证注意力编码仍可独立完成。

## 7. 怎样读最终结果

主要看同一测试任务中的未来误差，再结合历史重构与整体误差。

对每个消融计算：

\[
\Delta E=E_{\mathrm{ablation}}-E_{\mathrm{forward}},\qquad
\text{相对误差降低}=\frac{\Delta E}{E_{\mathrm{ablation}}}.
\]

正值表示原正向ODE方案误差更小。方向组量化“正向估计截止状态”相对“反向估计起点再向前生成”的收益。注意力组量化原ODE递推编码相对时间注意力编码的收益。两者分别与同一个参照比较。

比较文档同时报告验证与测试的历史、未来、整体误差，校正前预测误差，以及平均Jacobian平方范数。各字段损失、有效观测数和完整设备信息保存到结构化比较文件。已有参照检查点会在CUDA上重新评价，核对共同评价代码。
