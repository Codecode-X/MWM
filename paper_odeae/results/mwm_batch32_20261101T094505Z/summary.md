# ADNI：MWM训练与比较

本轮GPU分配：GPU 0运行MWM主版本，GPU 1运行A，GPU 3运行B；GPU 2保留备用。

## 1. 本轮怎样训练

三组均按检查时间顺序读取历史。首次观测年龄用于INIT，首次观测经UPDATE形成初始估计；此后每次先用ODE预测当前检查，再吸收当前检查。历史截止点之后只做ODE预测。

每组使用单张RTX 4090、seed 0、batch 32，每个batch执行一次梯度更新，无梯度累积。最多300轮、至少50轮，验证分数连续40轮未改善时早停。全部训练接入SwanLab。

三组统一用验证集未加权的逐次预测MSE＋交叉熵选择检查点。A的计数权重和B的NLL只作用于训练，三组的选择标准相同。

## 2. 损失和参数量

| 版本 | 数据监督 | INIT / UPDATE / Decoder / ODE隐藏宽度 | 参数量 |
|---|---|---|---:|
| MWM main | 数值MSE＋类别交叉熵；全部观测同权 | 159 / 159 / 159 / 188 | 44,875 |
| MWM A | 在主版本上，乘sigmoid(N−3)；N为已吸收的观测条数 | 159 / 159 / 159 / 188 | 44,875 |
| MWM B | 数值Gaussian NLL＋类别交叉熵；输出每时刻一个σ | 159 / 160 / 158 / 187 | 44,875 |

三组均保留0.01 Jacobian和0.02共享ODE参数L2，移除旧的0.01 weak_prior独立项。B用少量隐藏宽度调整容纳29个σ头参数，总参数量与主版本完全相同。B的σ使用softplus＋0.01，初始值为1；log σ按每个有效数值字段计入NLL。
